- **태그:** 전역일계산기, 전역일, 군대전역일, 복무율, 군복무기간, 사회복무요원소집해제일

## 계산 기준 (2026-11-13 확인)
- **전역일** = 입대일 + 복무 개월 수 − 1일. 입대일을 첫날로 세는 달력 계산(민법 제160조: 월로 정한 기간은 마지막 달의 기산일에 해당하는 날의 전날에 만료, 해당일이 없으면 그 달 말일에 만료).
  - 월말 처리: 2025-08-28 입대(육군) → 2027-02-27, 2025-08-29·30·31 입대 → 모두 2027-02-28. JS `Date` 의 날짜 넘김(2월 31일 → 3월 3일)을 쓰지 않고 말일로 고정한다.
- **조정 일수**(선택): 당김(조기전역) −N일 / 늦춤(징계·군기교육 등) +N일, 0~999일. 전역일에 그대로 더한다. 결과가 입대일보다 앞서면 빨간 안내.
- **전체 복무일수** = 전역일 − 입대일 + 1 (양 끝 포함)
- **지난 일수** = 기준일 − 입대일 + 1 (입대일 = 1일째). 기준일이 입대일 전이면 0, 전역일 뒤면 전체 일수.
- **복무율** = 지난 일수 ÷ 전체 복무일수 × 100, 소수 첫째 자리 버림. 전역일 당일 100%.
- **D-day** = 전역일 − 기준일. 0이면 "오늘 전역", 음수면 D+N, 기준일이 입대일 전이면 "입대까지 D-N".
- 입대 연도 범위 2000~2100년. 2021년 이전 입대는 단계적 단축 시기라 실제와 다를 수 있다는 안내 문구를 붙인다.

## 확인하지 못한 것 / 넣지 않은 것
- 이 작업 환경에서 mma.go.kr·law.go.kr·korea.kr 직접 접속이 막혀 있어, 위 수치는 검색 결과에 나온 공식 페이지 요약으로 확인했다.
- **진급 예상일은 위젯에 넣지 않았다.** 최저복무기간(2·6·6개월)은 보도로 확인했지만, 진급일 산정 방식(매월 1일 진급, 입영 월 산입 여부)은 훈령 원문으로 확인하지 못했고 2024년부터 진급 심사로 누락될 수 있어서다. 글 FAQ에만 "보통 약 2·8·14개월, 부대 확인 필요"로 적었다.
- **2026년 병 봉급은 넣지 않았다.** 블로그·정보 사이트에는 "이병 75만·일병 90만·상병 120만·병장 150만 원(2025년과 동일)"으로 나오지만 국방부·정책브리핑 원문으로 확인하지 못했다(정책브리핑은 "2025년 병장 150만 원" 목표까지만 확인).
- 산업기능요원·전문연구요원의 군사교육소집 기간 산입, 복무 중 연장·정지 사유는 반영하지 않는다(위젯 안내 문구로만 표시).
- 전역일이 주말·공휴일일 때 앞당기는지 등 실무 처리는 확인하지 못해 계산·글에 넣지 않았다.
- 100일 휴가 등 휴가 일정은 부대별로 달라 넣지 않았다.
