# 출산 후 신청할 것 타임라인

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 위젯 + 계산법 + 표 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 위젯만. 출생일(또는 예정일)·몇째·부모 근로 형태·시도를 넣으면 할 일을 기한 순서 카드로 보여 줌 |

- **제목 추천:** 출산 후 신청할 것 총정리 - 출생신고·부모급여·첫만남이용권 기한 타임라인
- **태그:** 출산후신청할것, 출생신고기한, 부모급여신청, 첫만남이용권, 배우자출산휴가, 행복출산원스톱

## 위젯 동작 (기준일 2026-11-20)
- 입력: 출생일(기본 오늘, 예정일 가능), 첫째/둘째 이상, 근로 형태(맞벌이·엄마만 직장·아빠만 직장·자영업·프리랜서·해당 없음), 시·도(선택).
- 카드 종류: 마감일(D-day, 지나면 "N일 지났어요"), 기간(시작 전 "N일 뒤 시작" / 진행 중 "마감 D-n" / 지남), 권장 시기(예방접종), 날짜 없는 규칙(출산전후휴가 급여·육아휴직·피부양자·지자체). 지난 카드는 흐리게 + "지금이라도 가능한지" 안내.
- 근로 형태별 표시: 출산전후휴가 급여(맞벌이·엄마만), 배우자 출산휴가(맞벌이·아빠만), 육아휴직(직장 있는 경우, 맞벌이면 6+6 안내), 출산급여 150만원(자영업·프리랜서), 자녀장려금(해당 없음 제외).
- 잘못된 입력: 없는 날짜, 출생 후 2년 경과(첫만남이용권 기한까지 끝남), 300일 넘는 미래.
- 기한 날짜는 **안전하게 이른 쪽**으로 잡았다. 말일이 토·일·공휴일이면 민법 제161조로 다음 날까지 인정될 수 있지만, 공휴일 표를 넣지 않고 화면 문구로만 안내한다.

### 기한 계산 규칙
| 항목 | 위젯 계산 | 근거 |
|---|---|---|
| 출생신고 | 출생일 + 1개월 − 1일(다음 달에 같은 날이 없으면 그 달 말일) | 가족관계등록법 제44조(1개월 이내), 제37조(신고기간은 신고사건 발생일부터 기산 → 초일 산입), 민법 제160조. 과태료 5만원 이하(제122조) |
| 행복출산 원스톱 | 출생신고 기한과 같은 날(권장) | 정부24 원스톱 서비스(출생신고와 함께 통합 신청) |
| 부모급여·아동수당 | 출생일 + 59일 | 출생일 포함 60일 이내 신청 시 출생일이 속한 달부터 소급(영유아보육법 부모급여 조문 발췌, 지자체 안내 "출생 후 60일(출생일 포함)") |
| 첫만남이용권 | 출생일 + 24개월 − 1일 | 2024.1.1 이후 출생아 사용기간 출생일부터 2년(저출산고령사회기본법 시행령 개정, 1년→2년). 울산 동구 예시 2025.1.1생 → 2026.12.31까지와 일치 |
| 산모·신생아 건강관리 | 출산(예정)일 − 40일 ~ 출생일 + 59일 | 2026 사업안내: 출산 예정일 40일 전 ~ 출산일로부터 60일. "60일까지" 기산이 불명확해 하루 이른 쪽으로 잡음. **브리프의 "출산 후 30일"은 유산·사산 신청기한(확인일부터 30일)과 혼동된 것으로 보여 60일을 사용** |
| BCG | 출생일 + 28일(생후 4주 이내) | 질병관리청 표준예방접종일정 |
| B형간염 1·2·3차, 2·4·6개월 접종 | 출생일, +1·2·4·6개월 같은 날(권장일) | 질병관리청 표준예방접종일정(0·1·6개월, DTaP 2·4·6개월, 로타 2·4(·6)개월) |
| 영유아 건강검진 1차 | 출생일 + 14일 ~ + 35일 | 건강검진기본법 시행규칙 등 "생후 14~35일, 14일 되는 날부터 35일이 끝나는 날까지" |
| 2차 / 3차 | +4개월 ~ +7개월 − 1일 / +9개월 ~ +13개월 − 1일 | 생후 4~6개월 / 9~12개월 (개월 끝나는 날까지로 해석) |
| 배우자 출산휴가 | 출산일 + 119일 | 남녀고용평등법 제18조의2: 20일, 출산일부터 120일 이내, 3회 분할(2025.2.23 시행). 출산일 포함 여부가 불명확해 이른 쪽 |
| 출산전후휴가 급여 | 날짜 없음(휴가 시작 1개월 뒤 ~ 끝난 날 이후 12개월) | 고용24·생활법령 안내, 출산 후 45일(다태아 60일) 이상 |
| 육아휴직 | 날짜 없음(시작 30일 전 신청) | 남녀고용평등법 시행령 제11조. 급여는 시작 1개월 뒤 ~ 끝난 날 이후 12개월 |
| 출산급여 150만원 | 출생일 + 12개월 − 1일 | 고용보험 미적용자 출산급여, 출산일부터 1년 이내 신청 |
| 자녀장려금 | 태어난 다음 해 5.1 ~ 5.31 | 조세특례제한법 정기 신청기간(support-calendar-2027 README와 동일) |
| 건강보험 피부양자, 지자체 출산지원금 | 날짜 없음 | 법정 기한 확인 못 함 → "출생신고 후 바로", "지역마다 다름"으로만 표시. 지자체 금액은 넣지 않음 |

## 확신이 낮은 부분
- 배우자 출산휴가 120일·산모신생아 60일에 출산일을 넣어 세는지 공식 예시를 찾지 못해 하루 이른 날로 표시했다.
- 건강보험 피부양자: 신생아 신고 기한(14일/90일 설이 엇갈림)과 원스톱 포함 여부를 확인하지 못해 기한 없이 "출생신고 후 바로"로만 썼다.
- 산모·신생아 건강관리 소득 기준(2026.10 이후 150% 초과 제외 등)은 지역 안내마다 달라 "지역마다 다름"으로만 썼다.
- 영유아 건강검진 2·3차 끝나는 날(6개월·12개월이 "끝나는 날")은 해석이다.
- 예방접종 권장일은 개월 수 같은 날로 표시했다(실제 접종 가능 범위는 의료기관 안내).
