# 글자수 세기

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 계산기 + 설명 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 계산기만 |

- **제목 추천:** 글자수 세기 - 공백 포함·제외, 바이트 수 바로 확인 (자소서 글자수 계산기)
- **태그:** 글자수세기, 글자수계산기, 자소서글자수, 공백포함글자수, 바이트계산기, 원고지매수

## 계산 기준 (기준일 2026-11-13)
- **공백 포함 글자수:** 사용자가 보는 글자(grapheme cluster) 개수. `Intl.Segmenter('ko', {granularity: 'grapheme'})` 사용, 미지원 브라우저는 `Array.from`(코드 포인트 단위)으로 대체. 이모지·결합 문자(👍🏽, 👨‍👩‍👧 등)는 1자. 줄바꿈도 1자.
- **공백 제외 글자수:** 위 글자 중 공백 문자(JS `\s`: 띄어쓰기, 탭, 줄바꿈, NBSP, 전각 공백 등)를 뺀 개수.
- **UTF-8 바이트:** 실제 UTF-8 인코딩 길이. U+0000~007F 1바이트, U+0080~07FF 2바이트, U+0800~FFFF 3바이트(한글), 그 이상(이모지 등) 4바이트.
- **EUC-KR 바이트(한글 2바이트):** 코드 포인트마다 ASCII(U+0000~007F)는 1바이트, 나머지는 2바이트로 셈. 국내 사이트의 흔한 "한글 2바이트" 계산 방식과 같은 간이 규칙이라, EUC-KR로 표현할 수 없는 글자(이모지, 완성형 2,350자에 없는 한글 등)도 2바이트로 세요.
- **단어 수:** 앞뒤 공백을 지우고 공백으로 나눈 덩어리 수(한국어는 어절 수).
- **줄 수:** 줄바꿈 개수 + 1(글이 비어 있으면 0). 마지막에 엔터를 치면 빈 줄도 1줄로 셈.
- **원고지 매수:** 공백 포함 글자수 ÷ 200 올림. 실제 원고지 작성법(문단 첫 칸 비우기, 문장부호 칸 등)은 반영하지 않은 간이 계산이라 위젯과 글에 안내함.
- **줄바꿈:** textarea 값 기준이라 항상 LF(`\n`) 1개 = 1자 = 1바이트. 윈도 방식(CRLF)으로 세는 제출처는 줄바꿈마다 1바이트씩 더 나올 수 있음.
- **목표 글자수:** 1~100,000자. 공백 포함/제외 중 고른 기준으로 남은/초과 글자수와 진행률 표시.
- **공백 정리:** 줄마다 연속 공백(탭·NBSP·전각 공백 포함)을 띄어쓰기 1개로, 줄 앞뒤 공백 삭제, 빈 줄은 최대 1줄, 글 앞뒤 빈 줄 삭제. 한 번 더 누르면 되돌리기.
- **다시 입력:** 글이 있으면 첫 클릭에 "한 번 더 누르면 지워져요"로 바뀌고 3초 안에 다시 눌러야 지워짐(실수 방지, confirm 없이).
- 입력한 글은 저장·전송하지 않음(네트워크 요청, localStorage 없음).

## 출처
- UTF-8 바이트 길이: RFC 3629 "UTF-8, a transformation format of ISO 10646" https://www.rfc-editor.org/rfc/rfc3629
- EUC-KR: KS X 1001(완성형) 기반, 한글·한자 2바이트, ASCII 1바이트. WHATWG Encoding Standard의 EUC-KR 항목 https://encoding.spec.whatwg.org/#euc-kr
- 글자(grapheme) 단위: Unicode UAX #29 Text Segmentation https://www.unicode.org/reports/tr29/ , MDN `Intl.Segmenter` https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Intl/Segmenter
- 원고지 200자: 200자 원고지(20자 × 10줄) 일반 규격. 매수 계산은 간이 규칙.
- 자기소개서 글자수 기준(공백 포함/제외, 줄바꿈 처리)은 채용 사이트마다 달라 공식 출처로 통일된 기준을 확인할 수 없음. 그래서 글에는 "제출처 안내를 따르고, 없으면 공백 포함으로 맞추라"는 일반 안내만 적었음.
