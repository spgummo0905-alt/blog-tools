# 헷갈리는 맞춤법 모음 + 퀴즈

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 퀴즈 위젯 + 구별법·표 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 퀴즈·빠른 찾기 위젯만 |

- **제목 추천:** 헷갈리는 맞춤법 총정리 + 퀴즈 - 되/돼, 안/않, 로서/로써 한 번에
- **태그:** 맞춤법, 헷갈리는맞춤법, 맞춤법퀴즈, 되돼구별, 안않구별, 로서로써, 며칠몇일

## 위젯 동작 (기준일 2026-11-13)
- **데이터:** 스크립트 안 배열 `Q` 하나. 한 원소 = 한 문제 `{k 항목, o 옳은 것, x 틀린 것(이 문장에 안 맞는 것), n(1이면 x는 아예 틀린 표기), s 예문(___ 자리), t 쉬운 구별법, b 근거}`. 28개 항목, 45개 예문. 같은 항목의 근거 `b`는 한 문자열로 통일(빠른 찾기 카드에서 한 번만 보이게).
- **퀴즈:** 항목이 겹치지 않게 10문제 무작위, 선택지 순서도 무작위. 고르면 바로 정답/오답 색 표시 + 구별법 + 근거, `다음 문제` → 마지막엔 `결과 보기`. 결과 화면: 점수, 한 줄 평, 틀린 문제 복습(정답을 채운 예문 + 구별법), `다시 풀기`, `결과 복사`.
  - CLAUDE.md의 `다시 입력` 버튼은 퀴즈 특성상 `다시 풀기`로 이름만 바꿈(같은 역할: 처음부터 다시).
  - 결과 복사 문구: `[맞춤법 퀴즈 결과] 10문제 중 N문제 맞혔어요!` + 틀린 항목 + 정답 예문 + `나도 풀어 보기: (글 주소)`. 글 주소는 `location.href`(http/https일 때만).
- **빠른 찾기:** 입력 즉시 검색. 공백·슬래시·따옴표 등을 지우고 항목 이름, 옳은/틀린 표기와 비교(완전 일치 > 포함 > 입력이 표기를 포함 > 앞 두 글자 일치 순), 최대 3개 카드. 없으면 빨간 안내 문구 + 전체 항목 칩. 빈칸이면 전체 항목 칩만.
- 오답 안내의 조사는 받침에 따라 `이에요/예요` 자동 선택.

## 다룬 항목과 근거
조항 번호는 검색으로 국립국어원 자료(또는 그 자료를 인용한 글)에서 확인한 것만 적었다. 나머지는 『표준국어대사전』 표제어 풀이로 적었다.

| 항목 | 근거 |
|---|---|
| 되/돼 (됬다 ✕) | 한글 맞춤법 제35항 [붙임 2] (되어 → 돼, 되었다 → 됐다) |
| 안/않 | 표준국어대사전 ‘안’(‘아니’의 준말), ‘않다’(‘아니하다’의 준말) |
| 로서/로써 | 한글 맞춤법 제57항 |
| 웬/왠지 | 표준국어대사전 ‘왠지’, ‘웬’, ‘웬일’ |
| 든지/던지 | 한글 맞춤법 제56항 |
| 며칠 (몇 일 ✕) | 한글 맞춤법 제27항 [붙임 2], 표준국어대사전 ‘며칠’ |
| 금세 (금새 ✕) | 표준국어대사전 ‘금세’(‘금시에’가 줄어든 말). ‘금새’는 물건값을 뜻하는 별개 단어라 위젯·글에 함께 적음 |
| 어떻게/어떡해 | 표준국어대사전 ‘어떡하다’, 국립국어원 「한글 맞춤법의 이해」 |
| 바라/바래 | 표준국어대사전 ‘바라다’, ‘바래다’, 표준어 규정 제11항(‘바램’은 비표준어) |
| 낫다/낳다/났다 | 표준국어대사전 ‘낫다’, ‘낳다’, ‘나다’ |
| 맞추다/맞히다 | 한글 맞춤법 제55항(맞추다), 표준국어대사전 ‘맞히다’ |
| 부치다/붙이다 | 한글 맞춤법 제57항 |
| 결재/결제 | 표준국어대사전 ‘결재’(決裁), ‘결제’(決濟) |
| 가르치다/가리키다 | 표준국어대사전 |
| 일절/일체 | 표준국어대사전 ‘일절’, ‘일체’(一切) |
| 데/대 | 국립국어원 「한글 맞춤법의 이해」(직접 경험 -데, 남의 말 전달 -대) |
| 율/률 | 한글 맞춤법 제11항 [붙임 1] |
| 할게 (할께 ✕) | 한글 맞춤법 제53항 (의문 어미 -ㄹ까, -ㄹ꼬 등만 된소리) |
| 오랜만 (오랫만 ✕) | 표준국어대사전 ‘오랜만’(‘오래간만’의 준말) |
| 역할 (역활 ✕) | 표준국어대사전 ‘역할’(役割) |
| 설렘 (설레임 ✕) | 표준국어대사전 ‘설레다’, 국립국어원 질의응답(‘설레이다’는 ‘설레다’의 잘못) |
| 굳이 (구지 ✕) | 표준국어대사전 ‘굳이’ |
| 희한하다 (희안하다 ✕) | 표준국어대사전 ‘희한하다’(稀罕) |
| 깨끗이 (깨끗히 ✕) | 한글 맞춤법 제51항 |
| 대가 (댓가 ✕) | 한글 맞춤법 제30항(사이시옷, 두 음절 한자어 예외 곳간·셋방·숫자·찻간·툇간·횟수) |
| 어이없다 (어의없다 ✕) | 표준국어대사전 ‘어이없다’ |
| 일부러 / 일부로 | 표준국어대사전 ‘일부러’. ‘일부로’는 ‘일부(一部)+로’일 때만 맞아서 “아예 틀린 표기”로 표시하지 않음 |
| 이따가/있다가 | 한글 맞춤법 제57항 |
