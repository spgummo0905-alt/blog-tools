## 판정 기준 (기준일 2026-11-20, 2026년 현행 기준을 2027년에 적용)
- **입력:** 출생연도(1920~2010, 4자리), 성별 칩, 가입 유형 칩(직장 사무직 / 직장 비사무직 / 지역가입자·피부양자 / 의료급여). 범위 밖·미래 연도는 빨간 안내.
- **나이:** a = 2027 − 출생연도(국가검진은 생일과 무관하게 연도로 나이를 셈. 근거: 질병관리청 "2025년부터 56세(25년 기준 1969년생)" C형간염 안내).
- **일반건강검진 대상(odd = 홀수년생):**
  - 직장 사무직: odd / 직장 비사무직: 항상 / 지역·피부양자: a ≥ 20 이고 odd(지역 세대주는 나이 무관이지만 위젯은 20세 미만을 대상 아님으로 처리하고 문구로 안내) / 의료급여: 20 ≤ a ≤ 64 이고 odd, a = 66 은 의료급여 생애전환기검진.
- **기본 항목:** 문진·진찰, 신체계측, 혈압, 시력·청력, 혈액(혈색소·공복혈당·간기능·크레아티닌/eGFR), 요단백, 구강검진. **흉부방사선은 a ≥ 50 만**(2027년부터).
- **연령별 추가 항목(odd 일 때만 표시. 정해진 나이가 모두 짝수라 2027년엔 홀수년생만 해당):**
  이상지질혈증 남 24·여 40세부터 4년마다, B형간염 40, C형간염 항체 56, 폐기능 56·66, 골밀도 여 54·60·66, 치면세균막 40, 생활습관평가 40·50·60·70, 인지기능장애 66세 이상 2년마다, 노인신체기능 66·70·80, 우울증 20~34세 2년마다·35~39/40대/50대/60대/70대 각 1회, 조기정신증 20~34세 2년마다.
- **암검진:** 위 40+ 2년(odd), 대장 50+ 매년, 간 40+ 고위험군 6개월(매년), 유방 여 40+ 2년(odd), 자궁경부 여 20+ 2년(odd), 폐 54~74 고위험군 2년(odd). 짝수년생에게는 2년 주기 암검진을 "2028년 차례"로 표시.
- **본인부담:** 일반검진·대장암·자궁경부암 무료. 위·유방·간·폐암은 보험료 상위 50% 10%, 하위 50%·의료급여 무료(위젯은 건강보험 가입자에게 "무료 또는 10%", 의료급여는 "무료").
- **미수검 안내:** 대상이면 "12. 31.까지, 놓치면 2028년 1월부터 전년도 미수검 추가 등록". 짝수년생(2026 대상이었던 사람)이면 "2026년 미수검이면 2027년 1월부터 추가 등록".

## 확신이 낮은 부분
- **2027년 공식 대상 공지 전**: 홀수년생 대상은 현행 2년 주기 규정을 그대로 적용한 것이다. 2027년 건강검진 실시기준 고시가 바뀌면 고친다.
- **우울증 40대 이상 기준**: 복지부 표는 "35~39·40~49·50~59·60~69·70~79세 각 1회", 일부 기사는 "10년 주기"로 표현한다. 위젯은 "연령대 중 1회(이미 받았으면 제외)"로 표시.
- **비사무직 짝수년생의 연령별 추가 항목**: 정해진 나이가 짝수라 2027년엔 해당 없음으로 처리했다(2년 주기 연령대 항목도 짝·홀 해에 맞춘다고 가정). 공단 조회 권장 문구로 보완.
- **의료급여 하한 연령**: 20세(보건소 안내)와 19세(일부 블로그)가 엇갈려 20세로 적었다. 65세·67세 이상 의료급여 수급권자는 "보건소 문의"로만 안내.
- **의료급여 생애전환기(66세) 세부 항목**: 일반검진 66세 항목과 같다고 보고 표시했다(우울증 포함 여부 미확인).
- **본인부담 10% 대상 암종**: 위·유방·간·폐 10%, 대장·자궁경부 무료로 적었다(국가암정보센터·서울시 안내 기준). 폐암 상담료 등 세부 차이는 반영 안 함.
- **누리집 메뉴 이름**: 공단 누리집 건강검진 메뉴는 '건강iN'에서 '건강모아'로 바뀐 것으로 보이나 확인하지 못해 글에는 "공단 누리집 건강검진 메뉴"로만 썼다.
- 흉부방사선 고위험 직업군 범위는 2027년 고시로 정해질 예정이라 글에는 예시(결핵·감염병 취약 사업장)만 적었다.

## 매년 할 일
1. 2027년 1월 건강검진 실시기준 고시가 나오면 항목·연령을 다시 확인한다(흉부방사선 고위험 직업군 범위 포함).
2. 2028년판은 폴더를 새로 만들고(`health-checkup-2028`) 위젯의 `YEAR = 2027`, `MAX`, 짝·홀 문구("2026년과 2028년", "2028년 차례", "2028년 1월부터")와 글의 출생연도 표를 다시 만든다(짝수년생 대상).
3. 대장내시경 1차 검진·폐암 대상 확대(2028 목표)가 확정되면 암검진 표·FAQ·위젯 `cancers()` 를 고친다.
4. 글을 고친 뒤 `post.html` 을 다시 만들고 `python3 scripts/sync_faq.py tools/health-checkup-2027/post.html` 실행.
