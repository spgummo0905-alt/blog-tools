# 랜덤 뽑기 모음 (사다리타기 · 돌림판 · 제비뽑기 · 팀 나누기)

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 도구 + 설명 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 도구만 |

- **제목 추천:** 사다리타기·돌림판·제비뽑기 - 설치 없이 바로 하는 랜덤 뽑기 모음
- **태그:** 사다리타기, 돌림판, 제비뽑기, 팀나누기, 랜덤뽑기, 복불복

## 동작 기준 (기준일 2026-11-13)
- **난수:** `crypto.getRandomValues`(32비트)로 뽑고, `0~n-1` 정수는 거절 샘플링(2^32를 n으로 나눈 나머지 구간은 버리고 다시 뽑기)으로 만들어 모듈로 편향이 없음. 섞기는 Fisher-Yates. `crypto`가 없는 아주 오래된 브라우저만 `Math.random`으로 대체.
- **사다리타기:** 2~10명, 높이 10단. 각 단에서 칸 사이마다 45% 확률로 가로줄을 긋되, 같은 단에서 이웃한 가로줄은 만들지 않음(한 세로줄에서 두 가로줄이 같은 높이로 만나지 않게). 모든 칸 사이에 가로줄이 최소 1개 있게 보정. 사다리만으로는 결과가 고르게 섞이지 않으므로(10단 4명일 때 1번이 원래 칸에 도착하는 비율이 약 30%) **아래 결과 칸 순서도 무작위로 섞어** 각 참가자의 결과가 정확히 1/n이 되게 함. 기본은 도착 전 결과를 `?`로 가림(체크 해제 가능).
- **돌림판:** 항목 2~20개(줄바꿈·쉼표 구분, 빈 항목 무시). 당첨 항목을 먼저 균등하게 뽑고, 그 칸 안의 15~85% 지점이 12시 바늘에 오도록 6바퀴 이상 회전 후 감속(4.2초, ease-out quartic). 비우면 예시 4개(짜장면·짬뽕·볶음밥·탕수육).
- **제비뽑기:** 전체 2~100장, 당첨 1장 이상 전체 미만. 만들 때 Fisher-Yates로 섞어 두고 누르는 제비를 공개.
- **팀 나누기:** 2~300명. 이름마다 32비트 무작위 키를 붙여 정렬(= 균등 섞기). 이름을 추가·수정해도 기존 이름의 키는 유지돼 결과가 크게 출렁이지 않고, `다시 섞기`로 키를 모두 새로 뽑음. 팀 수 T면 앞쪽 (인원 mod T)팀이 1명 더 많음. 팀당 인원 s면 T = ceil(인원 / s)로 정해 어느 팀도 s명을 넘지 않음(예: 10명·3명씩 → 3·3·2·2). 같은 이름은 여러 번 넣으면 각각 따로 배정.
- **애니메이션:** `prefers-reduced-motion: reduce`면 사다리 선 그리기·돌림판 회전·카드 뒤집기 없이 결과만 바로 표시.
- 입력값은 탭별로 화면에만 있고 localStorage·쿠키·네트워크 전송 없음. 새로고침하면 초기화.
- 사다리 SVG는 실제 너비를 읽어 다시 그림(ResizeObserver) → 360px에서도 넘치지 않음. 돌림판은 viewBox 기반이라 최대 300px 안에서 자동 축소.

## 검증 (Playwright, 기준일)
- 사다리 2~10명 × 300회 생성: 이웃 가로줄 겹침 0, 가로줄 없는 칸 0, 항상 1:1 대응. 4명 2,000회에서 1번 참가자 결과 A/B/C/D = 483/492/499/526.
- 돌림판 4항목 8,000회: 1,971 / 2,010 / 1,931 / 2,088. 800회 바늘 위치와 결과 표시 불일치 0.
- 팀 나누기 4명 2팀 600회: 특정 두 사람이 같은 팀 비율 0.348(이론값 1/3).

## 출처
- MDN `Crypto.getRandomValues()` https://developer.mozilla.org/docs/Web/API/Crypto/getRandomValues (암호학적으로 강한 난수, `Math.random`과의 차이). 이 작업 환경에서는 MDN 접속이 막혀 있어 페이지를 직접 다시 열어 보지 못함. 기능 설명은 Web Crypto API 표준 내용과 일치.
- W3C Web Cryptography API https://www.w3.org/TR/WebCryptoAPI/#Crypto-method-getRandomValues
- 법령·금액 수치 없음.
