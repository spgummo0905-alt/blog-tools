    도구별 사용법

    사다리타기

    참가자 수를 2~10명 사이로 고르고, 왼쪽 칸에 이름, 오른쪽 칸에 결과(당첨, 꽝, 벌칙 등)를 적어요. 비워 두면 "참가자1", "당첨", "꽝"처럼 회색 글씨가 그대로 들어가요. 사다리 위쪽 이름을 누르면 선이 사다리를 따라 내려가고, 도착한 칸의 결과가 열려요. 전체 결과 보기를 누르면 모두의 결과를 한 번에 볼 수 있고, 다시 하기를 누르면 가로줄을 새로 그려요.

    돌림판

    항목을 2~20개 줄바꿈이나 쉼표로 구분해 적으면 원판이 바로 만들어져요. 돌리기를 누르면 원판이 천천히 느려지다가 멈추고, 위쪽 바늘이 가리키는 항목이 결과로 나와요.

    제비뽑기

    전체 제비 수(2~100장)와 당첨 수를 넣으면 번호가 적힌 제비가 깔려요. 한 사람씩 원하는 제비를 눌러 뒤집으면 당첨인지 꽝인지 나오고, 아래에 남은 제비와 남은 당첨 수가 표시돼요.

    팀 나누기

    이름을 줄바꿈이나 쉼표로 적고, 팀 수 또는 팀당 인원을 정하면 바로 팀이 나뉘어요. 마음에 안 들면 다시 섞기를 누르면 돼요.

    무작위로 정하는 원리

    이 도구는 브라우저에 들어 있는 암호학적 난수 생성기(crypto.getRandomValues)로 결과를 정해요. 보안용 비밀번호나 암호 키를 만들 때 쓰는 기능이라 다음 결과를 미리 맞히기 어렵고, 특정 항목이 더 잘 나오도록 조작돼 있지 않아요.

    • 공식: 항목이 n개면 각 항목이 뽑힐 확률은 1/n이에요.
    • 사다리타기: 가로줄 위치와 아래 결과 칸의 순서를 모두 무작위로 정해서, 어느 줄을 고르든 결과가 n개 중 하나로 고르게 나와요.
    • 제비뽑기: 전체 n장 중 당첨이 k장이면, 처음 뽑는 사람의 당첨 확률은 k/n이에요. 순서가 뒤라도 앞사람 결과를 모르는 상태라면 당첨 확률은 똑같이 k/n이에요.
    • 팀 나누기: 이름 전체를 무작위로 섞은 뒤 앞에서부터 팀에 나눠 담아요. 인원이 딱 나누어떨어지지 않으면 팀별 인원 차이는 최대 1명이에요.

    예를 들어 10명이 제비 10장(당첨 2장)을 뽑으면 첫 번째 사람도, 열 번째 사람도 당첨 확률은 2/10 = 20%예요. 먼저 뽑는다고 유리하지 않아요.

    자주 묻는 질문

    정말 공정하게 무작위로 뽑히나요?

    네. 결과는 브라우저의 암호학적 난수 생성기(crypto.getRandomValues)로 정하고, 특정 항목이나 순서에 가중치를 주지 않아요. 사다리타기도 아래 결과 칸 순서까지 무작위로 섞어서 어느 줄을 고르든 확률이 같아요.

    제비뽑기는 먼저 뽑는 게 유리한가요?

    아니요. 앞사람 결과를 모르고 뽑는다면 몇 번째로 뽑든 당첨 확률은 "당첨 수 ÷ 전체 제비 수"로 같아요. 다만 앞에서 당첨이 나온 걸 보고 난 뒤라면 남은 제비 기준으로 확률이 달라져요.

    입력한 이름이 저장되거나 전송되나요?

    아니요. 모든 계산은 내 휴대폰이나 컴퓨터 브라우저 안에서만 이뤄지고 어디에도 저장·전송되지 않아요. 새로고침하면 입력한 내용이 모두 지워져요.

    결과를 단톡방에 공유할 수 있나요?

    네. 각 탭의 결과 복사 버튼을 누르면 "1팀: 철수, 영희 / 2팀: 민수, 지영"처럼 정리된 글이 복사돼요. 카카오톡 같은 메신저에 그대로 붙여 넣으면 돼요.

    몇 명까지 넣을 수 있나요?

    사다리타기는 2~10명, 돌림판은 항목 2~20개, 제비뽑기는 2~100장, 팀 나누기는 2~300명까지 넣을 수 있어요. 인원이 많으면 사다리 대신 팀 나누기나 제비뽑기를 쓰는 게 보기 편해요.
