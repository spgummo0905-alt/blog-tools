# 2027년 손없는날 달력 (이사하기 좋은 날)

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 손없는날 달력 위젯 + 계산법 + 월별 표 + 주말·공휴일 손없는날 표 + 의미 + 이사 비용 팁 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 위젯만. 다른 글(이사·부동산 글 등)에 손없는날 달력만 넣고 싶을 때 사용 |

- **제목 추천:** 2027년 손없는날 달력 - 이사하기 좋은 날 월별 총정리 (주말 손없는날 포함)
- **태그:** 2027손없는날, 2027년손없는날, 손없는날, 이사하기좋은날, 손없는날달력, 주말손없는날

## 위젯 기능
- 오늘 이후 가장 가까운 손없는날 D-day (2027년 전에는 "가장 가까운 2027년 손없는날" = 1. 6., 2027. 12. 28. 이후엔 "모두 지났어요")
- 월 달력: 손없는날(파란 칸), 주말·공휴일 손없는날(진한 파란 테두리), 토(파랑)/일·공휴일(빨강), 칸마다 음력 일(음력 1일은 `월.1`)
- "주말·공휴일 손없는날만 보기" 토글, 월별 손없는날 목록과 개수(`손없는날 n일 · 주말·공휴일 n일`)
- 날짜 확인: 2027년 월·일 입력(또는 달력 칸 클릭) → 음력, 손없는날 여부, 바로 앞/뒤 손없는날. 없는 날짜(2/29, 4/31, 13월, 0일)는 빨간 안내. `결과 복사`, `다시 입력`.

## 계산 기준 (기준일 2026-11-20)
- **손없는날 = 음력 날짜 끝자리가 9·0인 날** (음력 9·10·19·20·29·30일).
- **음력 계산:** 한국천문연구원(KASI) 음양력과 같은 규칙으로 직접 계산했다. 합삭(삭) 시각을 한국 표준시(UTC+9)로 따져 합삭이 있는 날 = 음력 1일, 동지(태양황경 270°)가 든 달 = 11월, 동지~동지 사이 달이 12개면 윤달 없음.
  - 합삭: Meeus 『Astronomical Algorithms』 49장 식(주기항 포함), ΔT 69.5초. 중기: 같은 책 25장 태양 황경(저정밀, 오차 약 ±15분).
  - 2027년 음력 달 시작일(양력): 2026-12-09(음 11월, 30일), 2027-01-08(12월, 30일), 02-07(1월, 29일), 03-08(2월, 30일), 04-07(3월, 29일), 05-06(4월, 30일), 06-05(5월, 29일), 07-04(6월, 29일), 08-02(7월, 30일), 09-01(8월, 29일), 09-30(9월, 29일), 10-29(10월, 30일), 11-28(11월, 30일), 12-28(12월, 30일), 다음 2028-01-27(음 2028년 1월 1일).
  - 합삭 시각이 자정에 가장 가까운 달: 2027-02-07 00:56 KST(설날, 56분 여유 — 설날 2/7과 일치), 2028-01-27 00:13 KST(2027년 범위 밖, 2027년 날짜에는 영향 없음). 나머지 달은 자정에서 2시간 이상 떨어져 있다.
  - 동지 2026-12-22 05:48, 2027-12-22 11:36 KST 사이 달이 12개 → **2027년 윤달 없음**.
  - 위젯의 `LSTART` 배열이 위 시작일 그대로다.
- **2027 공휴일:** `tools/holidays-2027` 위젯의 `HOLI` 배열을 그대로 복사(우주항공청 2027년 월력요항 기준). 공휴일이 바뀌면 두 위젯을 함께 고친다.
- 주말·공휴일 손없는날 = 토·일요일이거나 관공서 공휴일(대체공휴일 포함)인 손없는날.

### 글에 쓴 숫자 (직접 계산, 위젯 결과와 일치)
- 손없는날 **68일** (월별 6·6·5·6·5·6·5·7·5·5·6·6). 주말 17일(토 9, 일 8) + 평일 공휴일 2일(5/5 어린이날, 12/27 대체공휴일) = **주말·공휴일 19일**, 평일(공휴일 아님) 49일.
- 2월 6일(토)은 설 연휴이면서 토요일, 10월 9일(토)은 한글날이면서 토요일 → 주말로 한 번만 셌다.
- 2027년 마지막 손없는날 12/27(월), 다음은 2028-01-05(수, 음 12.9).

## 확인하지 못한 것
- 이 작업 환경에서 astro.kasi.re.kr, month2k.com 에 직접 접속하지 못했다(호스트 차단). KASI 값은 웹 검색 결과 요약으로 대조했다. 위 표의 12개 이상 기준값과 총 68일·주말 17일이 모두 맞는다.
- 이사 비용이 손없는날에 얼마나 오르는지는 공식 통계가 없어 글에 퍼센트·금액을 쓰지 않았다("업체·지역마다 다름").
- 한국민속대백과사전 원문 항목은 직접 보지 못했다. 방위 순서(1·2일 동, 3·4일 남, 5·6일 서, 7·8일 북)는 백과사전을 인용한 2차 자료와 한국민족문화대백과사전 검색 요약 기준. 9일(하늘)·10일(땅)을 구분하는 고전 설명도 있으나 글에는 널리 쓰는 9·0 기준만 적었다.
