## 계산 기준 (기준일 2026-11-26)
국민건강보험법 시행규칙 별표 1(부양요건), 별표 1의2(소득 및 재산요건, 최종 개정 2025. 4. 23.). 모든 금액은 만원 단위 정수.

1. **연 소득 합계** `inc` = 공적연금 + 근로소득(총급여) + 사업소득금액 + 기타소득금액 + 금융소득(이자+배당 합계가 1,000만원 **초과**면 전액, 이하면 0)
   - 사적연금(연금저축·IRP·퇴직연금)과 일용근로소득은 넣지 않음
2. **소득요건** (별표 1의2 제1호)
   - 가목: `inc ≤ 2,000`
   - 나목: 사업소득 없음. 예외 ① 사업자 미등록(주택임대소득 있는 경우 제외)이고 사업소득 ≤ 500 ② 등록 장애인·국가유공/보훈보상 상이자이고 사업소득 ≤ 500
     - 위젯: 사업소득 > 0 이면 "미등록 / 등록 / 주택임대" 선택. 등록·주택임대는 1만원이라도 탈락. 장애인·상이자는 유형과 관계없이 500 이하 통과
   - 라목: 기혼자는 부부 모두 가~다목 충족 → 관계가 부모·자녀일 때 "배우자 있음"이면 배우자 합산소득 ≤ 2,000, 배우자 사업소득 요건(선택 칩) 확인. 관계가 배우자면 칸 숨김(상대가 직장가입자)
3. **재산요건** (별표 1의2 제2호, 재산세 과세표준 합계, 개인별)
   - 배우자·직계존속·직계비속: `prop ≤ 54,000` 통과 / `54,000 < prop ≤ 90,000` 이면 `inc ≤ 1,000`일 때만 / `prop > 90,000` 탈락
   - 형제·자매: `prop ≤ 18,000`
4. **형제·자매 부양요건** (별표 1): 미혼(이혼·사별 포함) 그리고 (만 30세 미만 또는 65세 이상 또는 장애인·상이자). 만 나이 0~120 입력
5. **결과 안내**: 통과 시 기준까지 여유(재산 5.4억 초과면 1,000만원 기준), 여유가 기준의 10% 이하면 노란 경고(공적연금 있으면 물가 인상 안내). 금융소득 800~1,000만원이면 "넘으면 전액 합산" 안내. 탈락 시 지역가입자 전환, 동반 탈락, 소득 감소 시 공단 문의, 2022. 9. 한시 경감 종료(2026. 8. 분까지) 안내
- 모든 경계값은 "이하"(같으면 통과): 소득 2,000, 재산 중간 구간 소득 1,000, 사업소득 500, 재산 54,000·90,000·18,000, 금융소득 1,000(같으면 제외)
- 2027년 1월부터 바뀌는 피부양자 기준은 발표된 것이 없어(2026-11-26 기준) 연도 칩을 두지 않음

### 바뀌면 고칠 값 (`widget.html` 상수)
- `INC_MAX`(2000), `FIN_FREE`(1000), `BIZ_FREE`(500), `PROP_BASE`(54000), `PROP_TOP`(90000), `PROP_MID_INC`(1000), `PROP_SIB`(18000), `SIB_YOUNG`/`SIB_OLD`(30/65)
- 일용근로소득 반영 개편이 확정·시행되면: 근로소득 힌트, 결과 카드 문구("일용근로소득 제외"), 글의 소득 표·"언제 다시 확인하고" 단락을 고치고 위젯에 입력칸 추가 검토
- 값을 바꾸면 글 첫 문단·계산법·표 2개·FAQ도 함께 고치고 `python3 scripts/sync_faq.py tools/dependent-eligibility-check/post.html` 실행
- 매년 11월: "2026년 11월에는 2025년 소득…" 문장의 연도 갱신

## 확인하지 못한 점 (솔직히 기록)
- 별표 원문을 직접 열지 못해 조문은 검색 엔진이 보여 준 법령 파일·공단 페이지 발췌로 확인했어요. 발행 전 공단 페이지를 한 번 열어 숫자를 대조하면 좋아요.
- 사업자 미등록 500만원 이하 사업소득을 "사업소득이 없는 것으로 본다"는 문구가 가목(2,000만원 합계)에도 적용되는지 확인하지 못해, 위젯은 보수적으로 합계에는 넣어요(합계 경계 근처에서만 차이).
- 장애인·상이자 사업소득 500만원 예외가 주택임대소득에도 적용되는지 원문으로 확인하지 못했어요. 위젯은 사업 유형과 관계없이 예외를 적용해요.
- 기타소득 중 분리과세(300만원 이하 선택 등) 처리, 근로소득이 있는 피부양자의 세부 처리는 확인하지 못해 "기타소득금액을 그대로 더함"으로만 계산해요.
- 2022. 9. 탈락자 한시 경감의 감면율(블로그마다 80→20% 또는 다른 설명)은 공식 자료로 확인하지 못해 글에는 "2026년 8월분으로 끝났다"는 사실만 썼어요.
- 매년 11월 정기 확인 때 자격 상실일(11월 또는 12월 1일)은 출처마다 달라 넣지 않았어요.
- 동거·비동거에 따른 부모·자녀 부양요건 세부(별표 1)는 위젯에 넣지 않고 글에서 "공단 확인"으로만 안내해요.
