## 계산 기준 (기준일 2026-11-26)
- **근거:** 「취업 후 학자금 상환 특별법」·시행령, 교육부 고시 상환기준소득, 소득세법 제47조(근로소득공제), 국세청·한국장학재단 안내.
- **입력:** 소득 연도(2025년 소득분 / 2026년 소득분, 기본 2026), 소득 유형(근로: 총급여 → 근로소득공제 자동 / 종합: 소득금액 직접), 대출 잔액(원리금, 선택), 금리(기본 1.7%, 0% 칩), 상환율(학부 20% / 대학원 25%).
- **계산식** (원 미만 버림)
  - 근로소득공제(소득세법 제47조): 500만 이하 70% / 1,500만 이하 350만+40% / 4,500만 이하 750만+15% / 1억 이하 1,200만+5% / 초과 1,475만+2%, 한도 2,000만원. `tools/salary-calculator` 의 `earnedDeduction` 과 같은 식.
  - 소득금액 = 총급여 − 근로소득공제 (종합소득자는 입력값)
  - 의무상환액 = max(소득금액 − 상환기준소득, 0) × 20%(대학원 25%), 대출 잔액을 넘으면 잔액까지만.
  - 월 원천공제액 = 의무상환액 ÷ 12 (원 미만 버림, "약"으로 표시). 의무상환액 36만원 미만이면 원천공제 없이 직접 납부로 표시.
  - 상환 완료 기간: 해마다 `잔액 × (1 + 금리)` 후 의무상환액 차감, 소득·금리 고정 가정. 의무상환액 ≥ 잔액이면 "1년 안", 의무상환액 ≤ 1년 이자면 "줄지 않음" 경고.

| 소득 연도 | 상환기준소득(소득금액) | 총급여 환산 | 근로소득자 원천공제 |
|---|---|---|---|
| 2024년 소득분 | 1,752만원 | 약 2,679만원 | 2025.7.~2026.6. (글 표에만) |
| 2025년 소득분 | 1,898만원 | 약 2,851만원 | 2026.7.~2027.6. |
| 2026년 소득분 | 2,056만원 | 약 3,037만원 | 2027.7.~2028.6. |
| 2027년 소득분 | 발표 전 | 발표 전 | 칩 넣지 않음 |

- 총급여 환산값은 근로소득공제 역산과 일치함을 확인했다(2,851만 → 소득금액 18,983,500원, 3,037만 → 20,564,500원, 2,679만 → 17,521,500원).
- **2027년 소득분:** 2026-11-26 현재 고시·2027학년도 1학기 학자금대출 기본계획을 찾지 못해 칩을 넣지 않았다(브리프: "2027 발표 시"). 보통 12월~1월 1학기 기본계획과 함께 발표된다.
- **금리·이자 면제(안내만, 계산은 사용자가 금리 입력):** 2026학년도 1·2학기 연 1.7% 동결. 2026.1.29 특별법 개정 의결 → 2026.7.1 학자금 지원 6구간(중위 130%) 이하로 "졸업 후 의무상환 개시 전 이자" 면제 확대 및 졸업 후 2년 제한 폐지, 2026.11.20 비수도권 대학생 8구간(중위 200%) 이하 확대. 2026.5.12 자립지원 대상자 포함 보도도 있으나 글에는 "기초·차상위·다자녀·5구간 이하"(기존)만 적었다.
- **계산하지 않는 것:** 근로+종합 합산 시 이미 원천공제된 금액 차감, 자발적 상환액 차감, 상환 유예, 양도·상속·증여소득 의무상환, 실제 연체·이자 계산 방식(단리/복리, 이자 납부 순서), 통지서의 10원 단위 처리.

## 확인하지 못한 것
- 교육부 고시 원문을 직접 열지 못했다. 2026년 소득분 2,056만원은 보도와 역산으로 맞춘 값이다.
- 종합소득자의 정확한 납부 기한·분할 납부 방식은 공식 자료로 확인하지 못해 "종합소득세 신고 뒤 국세청 결정·고지, 고지서 기한까지"로만 적었다.
- 미리납부 기한(5월 말 / 6월 1일 / 6월 말 등 보도마다 다름)은 숫자 없이 "통지서 확인"으로 적었다.
- 퇴사 시 남은 의무상환액 처리 방식은 확인하지 못해 FAQ에 "국세청 누리집·126에서 확인"으로 적었다.
- 원천공제 월액의 10원 단위 절사 여부는 확인 못 해 원 미만 버림 + "약"으로 표시했다.
- 대출 이자 계산을 연 복리로 단순화했다(실제 ICL 이자 계산·충당 순서와 다를 수 있음).
