## 계산 기준 (기준일 2026-11-13, 주택 유상취득·매매만)
- 과세표준 = 입력한 취득가액(실제 매매가). 세액은 항목마다 10원 미만 버림.
- **취득세 (지방세법 제11조 제1항 제8호)**: 개인 1주택·일시적 2주택·비조정대상지역 2주택은 6억 이하 1%, 9억 초과 3%, 6억 초과 9억 이하는 (취득가액 × 2/3억 − 3) × 1/100. 세율은 소수점 이하 다섯째 자리에서 반올림해 넷째 자리까지(= % 기준 소수 둘째 자리, 7억 → 1.67%). 위젯에서는 `Math.round(가액 / 1,500,000 − 300)` bp로 계산.
- **중과 (지방세법 제13조의2)**: 조정대상지역 2주택 8%(일시적 2주택 제외), 조정 3주택 이상 12%, 비조정 3주택 8%, 4주택 이상 12%, 법인 12%. 조정대상지역 여부는 새로 사는 주택 기준.
- **지방교육세 (지방세법 제151조)**: 일반세율 주택 = 취득세율 × 50% × 20% (= 취득세율의 1/10), 중과 = (4% − 2%) × 20% = 0.4%.
- **농어촌특별세 (농어촌특별세법 제5조, 제4조)**: 전용 85㎡ 이하(국민주택규모) 비과세. 85㎡ 초과는 일반 0.2%, 8% 중과 0.6%, 12% 중과 1.0%.
- **감면 (지방세특례제한법)**: 개인이 사서 1주택이 되고 취득가액 12억 원 이하일 때만. 감면액 = min(취득세, 한도). 생애최초 200만원(제36조의3), 생애최초 소형주택(전용 60㎡ 이하·아파트 제외·수도권 6억/그 밖 3억 이하)·인구감소지역 300만원, 출산·양육(제36조의5) 500만원. 모두 2028. 12. 31. 취득분까지. 12억 초과면 감면 없이 계산하고 안내 문구 표시.
- 감면은 **취득세에서만** 빼고 지방교육세·농특세는 감면 전 세율로 계산(대부분의 민간 계산기와 같은 방식). 위젯·글에 "감면을 받으면 지방교육세·농특세가 조금 다를 수 있다"고 안내.

## 출처
- 다주택 중과세율 유지: 2022.12 정부 완화안(조정 2주택 1~3% 등)은 지방세법 개정이 안 돼 제13조의2 그대로 적용. 2026년 지방세제 개편안(행정안전부, 2026.8.26 발표)에도 중과세율 인하는 없음. 국가법령정보센터 지방세법 https://www.law.go.kr , 행정안전부 https://www.mois.go.kr/frt/bbs/type010/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000008&nttId=129005

### 확인 한계 (솔직히)
- 이 환경에서 law.go.kr, korea.kr, wetax.go.kr, 지자체 계산기 페이지는 직접 열리지 않아 검색 결과의 공식 페이지 요약과 지자체·언론 보도로 교차 확인했어요.
- **감면 시 지방교육세·농특세 처리**는 확정하지 못했어요. 지방세법 제151조는 "취득세 감면율을 정하는 경우 지방교육세도 그 감면율로 감면"하는 구조라, 생애최초처럼 취득세 **전액 면제**(산출세액 ≤ 한도)면 지방교육세도 면제될 가능성이 있고, 85㎡ 초과 주택은 감면세액의 20%가 농특세로 붙을 수 있어요(농어촌특별세법 제5조 제1항 제1호). 민간 계산기마다 처리가 달라 위젯은 취득세에서만 빼고 안내 문구를 달았어요. 위택스 결과로 확인되면 `calc()`의 감면 부분을 고치세요.
- 세율 반올림 자릿수(7억 → 1.67%)는 법 조문 문구 "소수점 이하 다섯째 자리 반올림"과 다수 계산기 결과로 판단했어요.

## 매년(또는 수시로) 할 일
1. **조정대상지역 지정·해제**(국토교통부 공고): 위젯 힌트 문구(서울 25개 구·경기 일부)와 `post.html` FAQ "조정대상지역은 어디인가요?" 수정.
2. **지방세특례제한법 개정(보통 12월 국회 통과, 1월 시행)**: 2026년 개편안이 통과되면 청년 300만원·오피스텔 감면을 감면 버튼과 글 감면 표에 반영. 감면 기한(현재 2028.12.31)이 바뀌면 표 수정.
3. **지방세법 중과세율 개정 여부** 확인: 바뀌면 위젯 상단 `R`(heavy8, heavy12, eduHeavy, rural)과 글의 세율 표 수정.
4. 위젯 제목·글 표의 연도 수정 후 `post.html` 다시 만들고 `python3 scripts/sync_faq.py tools/acquisition-tax-calculator/post.html` 실행.
