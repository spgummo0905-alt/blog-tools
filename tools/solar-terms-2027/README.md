# 2027년 24절기·기념일 달력

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 달력 위젯 + 절기 계산법 + 24절기 표 + 세시풍속 표 + 기념일·데이 표 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 위젯만. 다른 글에 절기·기념일 달력만 넣고 싶을 때 사용 |

- **제목 추천:** 2027년 24절기 날짜 총정리 - 입춘·하지·동지 + 기념일·데이 달력
- **태그:** 2027년24절기, 2027절기, 2027입춘, 2027동지, 2027복날, 2027기념일

## 위젯 동작
- 기준일(년·월·일, 처음엔 오늘 날짜) → 그날 이후 **다음 절기**, **다음 기념일**(절기만인 항목 제외, 기준일 당일이면 `D-Day`)을 보여 준다. 2027-12-22(동지) 다음은 절기 없음, 2027-12-27 다음은 기념일 없음 → "2027년 일정이 모두 지났어요".
- 월 탭(1~12월) + 종류 칩(전체/절기/세시/공휴일/기념일/데이) → 그 달 목록. 항목을 누르면 한 줄 설명(뜻·풍습)이 펼쳐진다. 기준일보다 지난 항목은 흐리게.
- 잘못된 입력: 연도 4자리 아님, 1900~2100 밖, 월 0·13, 없는 날(2/29, 4/31) → 빨간 안내, D-day 숨김. 숫자 외 문자는 지워진다.
- `다시 입력` = 오늘 날짜·전체 칩으로 되돌림. `결과 복사` = D-day 2개 + 보고 있는 달 목록.
- 데이터는 `EV` 배열 하나. 종류는 공백으로 여러 개(예: `'term sesi'` 입추·칠석).

## 계산 기준 (기준일 2026-11-20)

### 24절기 (날짜만 표시, 시각은 표시 안 함)
- 정의: 태양의 겉보기 황경이 15°×n 이 되는 순간(춘분 0°, 입춘 315°, 동지 270°)을 **한국 표준시(UTC+9)** 날짜로.
- 검증 방법: 이 환경에서 astro.kasi.re.kr 접속이 막혀 있어 원문 표를 직접 보지 못했다. 그래서
  1. 웹 검색 결과에 인용된 한국천문연구원 2027 달력자료 값(및 같은 표를 옮긴 여러 사이트)의 24개 날짜와,
  2. 직접 계산한 값(Meeus 『Astronomical Algorithms』 25장 태양 위치 + 장동·광행차, ΔT 69.5초; 스크래치 `astro.py`)
  
  을 비교했고 **24개 날짜가 모두 일치**했다. 계산 시각은 검색된 값보다 1~6분 이르다(저정밀 공식 오차). 자정에 가장 가까운 상강(검색 00:32~00:33, 계산 00:27)·입동(00:38~00:39 / 00:37)·소한(23:09 / 23:05)도 날짜는 바뀌지 않는다.
- 분 단위 시각은 출처마다 1~4분씩 달라(예: 하지 23:10 vs 23:11, 입춘 10:42 vs 10:46) **확인된 값이 아니므로 글·위젯에 넣지 않았다.** 글에는 "오전 10시 40분대", "0시 30분 무렵"처럼 모든 값이 동의하는 범위만 썼다.

### 음력 세시 (2027년 윤달 없음)
- 음력 초하루 = 합삭(신월)이 드는 한국 표준시 날짜. Meeus 49장 신월 공식(주기항 + 행성 보정)으로 계산: 2027-01-08, **02-07**, 03-08, 04-07, **05-06**, **06-05**, 07-04, **08-02**, **09-01**, 09-30, 10-29, 11-28, 12-28 (굵게 = 설날·부처님오신날·단오·칠석·추석 공식 날짜로 역산되는 초하루와 일치). 가장 자정에 가까운 합삭은 2/7 00:56 이지만 설날 2/7은 월력요항으로 확정.
- 정월대보름 2/21(음1/15), 단오 6/9(음5/5), 칠석 8/8(음7/7)은 검색된 한국천문연구원 달력자료 인용값과 일치. 삼짇날 4/9(음3/3), 유두 7/18(음6/15), 백중 8/16(음7/15), 중양절 10/8(음9/9)은 위 초하루로 계산(직접 공식 표 확인은 못 함).
- 동지 12/22 = 음력 11/25 (11/1 = 11/28) → 노동지(음력 11월 21일 이후).
- 한식 = 동지(2026-12-22)부터 105일째 = 2027-04-06(화). 같은 방식으로 2025 한식 4/5 재현. DateDB 등 검색값 4/6과 일치.
- 삼복: 초복 = 하지 뒤 셋째 경일(庚日), 중복 = 넷째 경일, 말복 = 입추 뒤 첫 경일. 2024(7/15·7/25·8/14)·2025(7/20·7/30·8/9) 실제 값으로 경일 기준을 맞춘 뒤 계산 → 2027 **7/20(화)·7/30(금)·8/9(월)**, 월복 아님. 검색 결과(달력닷컴 등)와 일치.
