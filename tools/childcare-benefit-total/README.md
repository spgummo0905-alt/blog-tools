# 육아 지원금 총액 계산기 (0세 ~ 아동수당 종료)

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 위젯 + 계산법 + 표 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 위젯만. 출생일(예정일)·몇째·어린이집 시작 시기를 넣으면 월별 수령액 타임라인과 총액을 보여 줌 |

- **제목 추천:** 육아 지원금 총액 계산기 - 부모급여·아동수당·첫만남이용권 0세부터 얼마 받나
- **태그:** 육아지원금총액, 부모급여, 아동수당, 첫만남이용권, 가정양육수당, 아동수당13세

## 위젯 동작 (기준일 2026-11-26)
- 입력: 출생일(Y/M/D, `오늘로` 버튼), 첫째/둘째 이상, 어린이집·유치원 시작(안 다님 / 생후 6개월 / 만 1세 / 만 2세 / 만 3세 = 개월 인덱스 -1·6·12·24·36).
- 개월 인덱스 `i` = 출생한 달 0, 다음 달 1 … (달력 월 기준). 매월 `i`에 맞는 금액을 더한다.
- 출력: 총액(현금 / 이용권·보육료 바우처 구분), 오늘까지 받은 금액·앞으로 받을 금액, 제도별 합계(기간·개월 수), 연도별 `<details>` 접기(올해 펼침, 지난 달은 회색 + `받음`), 안내 문구(지자체 별도 등). `결과 복사`는 요약 + 제도별 + 연도별 합계.
- "받은 금액" 판정: 그달 25일(지급일)이 오늘 이전이면 받음. 출생일이 25일 뒤면 출생월분은 다음 달 25일 소급으로 본다. 첫만남이용권은 출생일에 받은 것으로 본다. 신청을 기한 안에 했다고 가정.
- 출생일 범위
  - **2024. 1. 1. 이후 ~ 오늘 + 300일:** 전체 계산(현행 부모급여 100/50만·첫만남 200/300만이 출생 때부터 적용된 세대).
  - **2017. 1. 1. ~ 2023. 12. 31.:** 과거 제도(2023 부모급여 70/35만, 2022 영아수당, 첫만남 일률 200만 등)가 달라 **앞으로 받을 아동수당·양육수당만** 계산하고 주황 안내. "오늘까지 받은 금액"은 `계산 안 함`.
  - **2016년 이전 출생:** 빨간 안내(남은 아동수당 없음). 없는 날짜, 300일 넘는 미래도 빨간 안내.
  - **2027. 7. 1. 이후 출생:** 아이맞이지원금 개편안(미확정) 주황 안내 + 현행 제도로 계산.

## 확신이 낮은 부분
- 아동수당 종료를 "생일 달의 전달까지"로 계산한 것은 개정 전 안내 기준이다. 개정법(2026. 3.) 조문 원문은 열어 보지 못했다.
- 연도 단계 확대가 매년 1월분부터 적용된다고 보았다(2026년은 1월분 소급, changes-2027은 2027. 1. 1.).
- 2018~2023년생도 끊김 없이 받는다는 결과는 연도별 상한을 그대로 적용한 계산 결과다(2017년생만 특례로 끊김 해소).
- 2024년·2025년 상반기 0세반 보육료(54만 가정)는 직접 확인하지 못했다. 총액에는 영향이 없고 현금/바우처 나눔만 바뀐다.
- 출생월이 0세반이 아닌 경우 등 반 편성 세부 규칙, 시간제 보육·종일제 아이돌봄 이용 시 양육수당 제한은 반영하지 않았다.
- 아이맞이지원금은 12월 국회 예산 처리 결과에 따라 반영 여부를 다시 정해야 한다.
