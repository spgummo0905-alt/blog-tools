# 2027년 세금·공과금 납부 달력

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 달력 위젯 + 연장 계산법 + 월별 일정 표 + 연장 표 + 납부 방법 + 가산세 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 위젯만. 다른 글에 납부 달력만 넣고 싶을 때 사용 |

- **제목 추천:** 2027 세금 납부 달력 - 자동차세·재산세·종소세 마감일 한눈에 (주말 연장 반영)
- **태그:** 2027세금달력, 세금납부일정, 자동차세연납, 재산세납부기간, 종합소득세신고기간, 세무일정

## 위젯이 하는 일
- 유형 칩 8개(직장인, 프리랜서, 일반과세자, 간이과세자, 면세사업자, 직원 둔 사업자, 집주인, 차량 소유자)를 여러 개 고르면 해당 일정만 모은다. 기본 선택: 직장인 + 차량 소유자.
- 오늘(또는 바꾼 기준일) 기준 다음 마감 D-day, 그다음 3건, 월 달력(마감일 테두리·점, 공휴일 빨강, 지난 마감 회색), 선택한 달의 일정 목록(기간, 실제 마감, "원래 ○ → 연장" 배지, 국세/지방세, 설명).
- 실제 마감일 = 법정 기한이 토·일·2027년 공휴일이면 다음 첫 평일(반복). 공휴일 배열 `HOLI`는 `tools/holidays-2027`과 같다.
- 잘못된 입력: 유형을 모두 끄면 "유형을 하나 이상 골라 주세요.", 기준일을 비우면 "기준일을 다시 골라 주세요.", 2026~2027년 밖이면 범위 안내(빨간 글씨, 결과 숨김). `다시 입력`은 선택을 비우고 기준일을 오늘로 되돌린다.
- `결과 복사`: 고른 유형의 2027년 전체 일정을 월별로(연장 사유 포함) 복사.
- 오늘이 2028년 이후면 "2027년 일정이 모두 지났어요".

## 확인하지 못한 것
- 국세청의 2027년 세무일정표 원문은 아직 찾지 못했다(검색 기준 미게시). 날짜는 법정 기한 + 연장 규칙으로 직접 계산했다.
- 국세기본법 제5조에 2026년 노동절 개정이 반영됐는지 원문 확인 못 함. 2027년 5/1은 토요일이라 결과에 영향 없음.
- 근로장려금 기한 후 신청 감액률(5% vs 10%)과 마감(11/30 vs 12/1)은 자료가 엇갈려 글에는 "기한 뒤 6개월 안, 조금 줄여서"로만 적었다.
- 간이과세자 예정부과 50만원 기준, 납부면제 4,800만원 기준, 주민세 사업소분 8천만원 기준, 성실신고 업종별 기준(5억·7.5억·15억)은 일반 안내 기준으로 적었고 원문은 못 봤다.
- 지방세 납부지연가산세 월 0.66%: 2026년 지방세기본법 개정안(입법예고 2026. 8.~9.)이 요율을 바꾸는지 확인 못 함.
- 임시공휴일·국세청/지자체 직권 연장(예: 2026년 1월 연납 2/4)은 반영하지 않음 → 위젯·글에 "바뀔 수 있음" 표시.
