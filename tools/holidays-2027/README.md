### 글에 쓴 숫자 (직접 계산, 언론 보도 수치와 일치)
- 공휴일 날짜 수 **24일** (대체공휴일 7일 포함). 토요일과 겹침 5일(2/6, 5/1, 7/17, 10/9, 12/25), 일요일과 겹침 4일(2/7, 6/6, 8/15, 10/3) → **평일 공휴일 15일**.
- 2027년은 1월 1일이 금요일인 평년 → 토 52일, 일 52일. 주 5일 근무자 쉬는 날 52 + 52 + 15 = **119일**.
- 관공서 공휴일 수(일요일 포함) 52 + 24 − 4 = **72일** (월력요항 보도: 적색 76일, 일요일 겹침 4일 빼고 72일).
- 연차 없이 3일 이상 연휴 **10번**: 1/1~3, 2/6~9(4일), 2/27~3/1, 5/1~3, 7/17~19, 8/14~16, 9/14~16, 10/2~4, 10/9~11, 12/25~27.
- 선거일: 2027년 전국 단위 공직선거 없음 (제21대 대선 2025.6.3 → 다음 대선 2030년, 제23대 총선 2028년, 제9회 지방선거 2026.6.3). 재·보궐선거일은 공휴일이 아님.
- 임시공휴일: 기준일 현재 지정 없음 → 글·위젯에 "지정되면 바뀔 수 있음" 표시.

## 위젯 계산 기준 (연차 꿀조합)
- 주 5일, 토·일 휴무, 관공서 공휴일·대체공휴일 모두 휴무. 연차는 **2027년의 평일(공휴일 아님)** 에만 쓴다.
- 이어진 평일 k일(1 ≤ k ≤ N)을 연차로 쓰면 앞뒤로 붙은 주말·공휴일까지 한 덩어리 → 연속 휴무 기간. 기간 안에 2027년 **평일 공휴일**이 하나 이상 있어야 후보.
- 해를 넘는 연휴를 위해 2026-12-01 ~ 2028-01-31을 계산하고, 경계 공휴일 2026-12-25(성탄절), 2028-01-01(신정, 토)만 넣었다. 연차는 2027년에만 쓰므로 연말 연휴는 2028-01-03(월) 첫 근무일에서 끝나고, 1월 초 연휴는 2026-12-31(목) 근무일에서 시작이 끊긴다.
- 고르기: 모든 후보를 (길이 내림차순, 연차 적은 순, 날짜 순)으로 정렬해 날짜가 겹치지 않는 것만 차례로 고른다 → 연휴별로 연차 N일 안에서 가장 긴 조합. 이걸 **효율(길이 ÷ 연차)** 내림차순, 길이 내림차순, 날짜 순으로 보여 주고(최대 10개), 가장 긴 것을 큰 숫자로 보여 준다.
- 연차 입력: 칩 1~5일 + 직접 입력 1~10일. 0, 11 이상은 빨간 안내. 숫자 외 문자는 지워진다.
