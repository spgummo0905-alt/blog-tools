# 이사 행정 타임라인 (전입신고·확정일자·대항력)

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 타임라인 위젯 + 기한 계산법 + 기한 표 + 대항력·근저당 설명 + 임대차 신고 표 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 타임라인 위젯만 |

- **제목 추천:** 이사 후 해야 할 일 - 전입신고·확정일자·대항력 날짜까지 타임라인 정리
- **태그:** 이사후해야할일, 전입신고기한, 확정일자, 대항력, 임대차신고, 이사체크리스트

## 위젯 입력과 계산 (기준일 2026-11-20)
- 입력: 이사일(기본 오늘), 계약 형태(전세/월세/매매), 계약일(선택), 잔금일(선택), 자동차 보유, 전학할 자녀.
- **법정 기한** = 시작일 + N일(첫날 불산입, 민법 제157조). 그날이 토·일·공휴일이면 다음 평일(민법 제161조, 지방세는 지방세기본법 제24조). 위젯 함수 `deadline()`.
- 공휴일 표 `HOLI`: 2026·2027년 관공서 공휴일(대체·임시공휴일 포함)만 들어 있어요. 2028년 이후는 주말만 반영 → **매년 다음 해 월력요항이 나오면 `HOLI`에 한 해씩 추가**.
  - 2026: 1/1, 2/16~18, 3/1, 3/2(대체), 5/1(노동절), 5/5, 5/24, 5/25(대체), 6/3(지방선거), 6/6, 7/17(제헌절), 8/15, 8/17(대체), 9/24~26, 10/3, 10/5(대체), 10/9, 12/25
  - 2027: `tools/holidays-2027/README.md`의 표와 같음
- **D-day**는 실제 오늘 기준. 지난 항목은 흐리게 + "지났어요" 안내. 체크 표시는 메모리에만(저장 안 함), 결과 복사는 `[ ]`/`[x]` 체크리스트.
- 잘못된 입력: 2000~2100년 밖 날짜, 계약일 > 이사일, 계약일 > 잔금일, 잔금일과 이사일 1년 넘게 차이.

## 확인하지 못한 점 (솔직히 기록)
- 이 환경에서 law.go.kr·korea.kr·khug.or.kr 원문 페이지는 열리지 않았어요(접속 차단). 웹 검색 결과 요약(언론 보도·지자체 안내·법률 해설)으로 교차 확인했어요.
- **전입신고 지연 과태료 금액**은 자료마다 달라요(최대 5만원 설명 vs 시행령 별표 4에 7일·1개월·3개월·6개월 구간으로 1만~10만원 설명). 그래서 글·위젯에는 금액 없이 "지연 기간에 따라 과태료"라고만 썼어요.
- 부동산 거래신고 지연 과태료 금액(500만원 이하 vs 100만원 이하 안내가 섞여 있음), 소유권이전등기 지연 과태료 금액도 확정하지 못해 금액은 쓰지 않았어요.
- HUG 반환보증 "계약기간 1/2 경과 전" 기준은 공식 페이지를 직접 보지 못했어요. 위젯은 "2년 계약이면 ○○ 전까지"로만 안내해요.
- 민법 제161조의 "공휴일"에 노동절(2026년부터 공휴일)·임시공휴일을 포함해 계산했어요.
- 우편물 전송 무료 권역 범위(같은 시·도 vs 9개 권역)는 보도마다 달라 "같은 권역 이사면 처음 3개월 무료"로만 썼어요.
