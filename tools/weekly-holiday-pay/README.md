# 주휴수당 계산기

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 계산기 + 설명 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 계산기만 |

- **제목 추천:** 주휴수당 계산기 - 2026·2027 최저시급 기준 주휴수당과 월급 바로 계산
- **태그:** 주휴수당, 주휴수당계산기, 주휴수당조건, 주휴수당계산법, 2027최저임금, 알바월급계산

## 계산 기준
- 주휴시간 = min(주 근무시간, 40) ÷ 40 × 8 (주 15시간 미만은 0)
- 월급 = round((주 근무시간 + 주휴시간) × 4.345) × 시급 (주 40시간이면 월 209시간)
- 연장·야간·휴일 가산수당은 계산하지 않음
