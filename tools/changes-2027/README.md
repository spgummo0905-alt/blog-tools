# 2027년 달라지는 것 총정리 (내 상황별 체크리스트)

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 위젯 + 4대보험 계산 예시 + 분야별 표 + 추진 중 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 위젯만 (내 상황 칩 다중 선택 + 키워드 → 해당 변화 카드) |

- **제목 추천:** 2027년 달라지는 것 총정리 - 최저임금·세금·육아·청년 지원 한눈에
- **태그:** 2027년달라지는것, 2027최저임금, 2027국민연금, 2027건강보험료, 2027아동수당, 2027년바뀌는제도

## 위젯이 하는 일
- 칩 8개(직장인, 자영업자·사업주, 부모·예비부모, 청년(19~34), 어르신(65+), 집주인·세입자, 운전자, 학생)를 여러 개 고르면, 고른 상황 중 **하나라도** 해당하는 변화만 보여 준다(OR). 아무것도 안 고르면 전체.
- 키워드(선택)는 이름·내용·영향·분야에서 공백을 무시하고 찾는다(AND로 칩 결과를 더 좁힘).
- 카드: 분야 배지, 시행일, 바뀌는 점, 나에게 미치는 영향. 확정(`ITEMS`)은 날짜순, 추진 중(`PENDING`)은 회색 점선 카드로 따로.
- 잘못된 입력(빨간 안내, 결과 숨김): 키워드에 한글·영문·숫자가 없음 / 결과 0개. 결과가 숨겨진 상태에서 `결과 복사` → 빨간 안내.
- `결과 복사`: ☐ 체크리스트(항목 + 시행일 + 나에게 영향) + 추진 중 목록. `다시 입력`: 칩·키워드 초기화.

## 계산 예시 (글 본문)
월 보수 300만원 직장인 본인 부담: 국민연금 300만 × 5% = 150,000원(2026년 142,500원) / 건강보험 300만 × 3.595% = 107,850원(동결) / 장기요양 107,850 × 0.9994 ÷ 7.19 = 14,991원(2026년 107,850 × 0.9448 ÷ 7.19 = 14,172원). 합계 약 8,300원 증가. 고용보험(0.9%)은 인상안 미확정이라 제외.

### 확신이 낮은 부분
- 고용보험 월 80만원 기준: 법률(보수 기준 전환)은 확정, 80만원은 시행령안 값. 글·위젯에 "시행령안"으로 표시함.
- 기초연금 거주 요건 시행일(2027. 4. 21.)과 출산 크레딧 둘째 15개월: 보도로만 확인(공포문 미확인).
- 군복무 크레딧 "2027년 전역자부터" 적용 범위: 보도 표현. 위젯에는 시행일만 적음.
- 고용·산재보험료 국세청 소득자료 부과의 정확한 시행일(2027. 1.)은 법률사무소·보도 요약으로만 확인.
- 배우자 출산휴가 출산 전 50일 사용 등 남녀고용평등법 개정은 시행일이 자료마다 달라(2026. 9. 18. / 2027. 1. 1.) 넣지 않았다.
- 2027년 1월 1일 시행 도로교통법 시행규칙(행정안전부령 제636호)은 내용 확인 못 해 넣지 않았다.
