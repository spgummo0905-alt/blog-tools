# 양육비 계산기

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 계산기 + 계산법 + 기준표 + 가산·감산 표 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 계산기만. 양육자·비양육자 세전 월소득(만원)과 자녀(최대 4명) 만 나이를 넣으면 자녀별 표준양육비·범위, 합계, 비양육자 분담비율·월 부담액, 계산식을 보여 줌 |

- **제목 추천:** 양육비 계산기 - 서울가정법원 산정기준표로 자녀 나이·부모 소득별 양육비 바로 계산
- **태그:** 양육비계산기, 양육비산정기준표, 표준양육비, 이혼양육비, 양육비분담, 양육비이행관리원
- 말투: 민감한 주제라 차분하고 정중하게. 위젯과 글에 "법률 자문 아님, 개별 사정에 따라 법원이 정함, 대한법률구조공단 132·가정법원 상담, 양육비이행관리원 1644-6621" 안내를 넣었다.

## 플랫폼별 붙여 넣는 곳
- **티스토리:** 글쓰기 → 우측 상단 `기본모드` → `HTML` 선택 → 붙여 넣기
- **블로거(Blogger):** 글쓰기 → 좌측 상단 연필 아이콘 → `HTML 보기` → 붙여 넣기
- **워드프레스(설치형):** 블록 추가 → `사용자 정의 HTML` → 붙여 넣기
  - wordpress.com 무료 요금제는 스크립트를 지워서 계산기가 작동하지 않음

## 계산 기준 (기준일 2026-11-26)

### 사용한 기준표
- 서울가정법원 「2021 양육비 산정기준표」: 2021. 12. 22. 공표, 2022. 3. 1. 시행. 2017년 기준표 이후 4년 만의 개정.
- **현행 여부:** 2026-11-26까지 검색한 범위에서 2022년 이후 새 기준표가 공표됐다는 공식 발표나 보도는 찾지 못했다. "2026 개정안"이라는 민간 블로그 글이 있지만 공식 출처가 없고 금액이 서로 달라 쓰지 않았다. 발행 전과 매년 서울가정법원 누리집(https://slfamily.scourt.go.kr) 새소식에서 다시 확인할 것.
- 표 구조: 부모 합산소득(세전) 11구간(0~199만원 … 1,000~1,199만원, 1,200만원 이상) × 자녀 만 나이 6구간(0~2, 3~5, 6~8, 9~11, 12~14, 15~18세). 칸마다 자녀 1인당 월 **평균값**과 **양육비 구간(하한~상한, 마지막 소득 구간은 하한 이상)**.
- 표준양육비는 "양육자녀가 2인인 4인 가구 기준, 자녀 1인당 평균양육비"(생활법령정보 설명).

### 위젯 계산
1. 합산소득 = 양육자 소득 + 비양육자 소득 (만원 단위 정수). 구간: 200 미만 → 0~199만원, 200~999 → 100만원 단위, 1,000~1,199, 1,200 이상.
2. 자녀별 표준양육비 = 해당 소득 구간 × 나이 구간 칸의 평균값 (범위도 함께 표시). 자녀 수만큼 더함.
3. 비양육자 분담액 = 합계 × 비양육자 소득 ÷ 합산소득, 원 단위 반올림.
4. 가산·감산은 **자동 적용하지 않는다.** 자녀 1명이면 "가산될 수 있음", 3명 이상이면 "감산될 수 있음" 안내만 표시.
   - 2021년 11월 공청회 기사(법률신문)에는 시안 단계에서 자녀 1명 가산계수 1.065, 3명 감산계수 0.783이 나오지만, 최종 공표본에 이 계수가 그대로 들어갔는지 원문을 확인하지 못해 글·위젯에 넣지 않았다. 생활법령정보는 "자녀 수(1인 가산, 3인 이상 감산)"처럼 방향만 적고 있다.
5. 잘못된 입력: 만 19세 이상(성년, 표 대상 아님), 두 소득 모두 0(비율 계산 불가), 월 소득 10억원(100,000만원) 이상.

## 확신이 낮은 부분
- 표 66칸 중 공식(법원·법제처·법원 발표 보도) 값과 직접 대조한 것은 위 6칸이고, 나머지는 민간 옮김본 + 내부 일관성 검사로 확인했다. 발행 전에 원문 PDF로 한 번 대조하면 좋다.
- 자녀 수 가산·감산 비율(시안 1.065/0.783)은 최종본 확인을 못 해 넣지 않았다.
- 소득에 들어가는 항목(근로·사업·임대·이자 등)은 생활법령·법률 칼럼 설명을 따랐다. 정부보조금·연금 포함 여부 등 세부는 해설서 원문을 확인하지 못했다.
- 양육비 지급 기간 "보통 성년(만 19세) 전까지"는 일반적인 실무 설명으로 적었다.
