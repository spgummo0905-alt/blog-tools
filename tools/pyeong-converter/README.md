# 평수 계산기

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 계산기 + 설명 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 계산기만. 다른 글(분양·이사 글 등)에 계산기만 넣고 싶을 때 사용 |

- **제목 추천:** 평수 계산기 - 평↔㎡ 바로 변환 (59·84㎡는 몇 평?)
- **태그:** 평수계산기, 평수계산, 평제곱미터, 84제곱미터몇평, 59제곱미터몇평, 전용면적공급면적

## 계산 기준
- 1평 = 6자 × 6자, 1자 = 10/33m → **1평 = 400/121㎡ ≈ 3.305785㎡**, 1㎡ = 121/400평 = 0.3025평
- 평 → ㎡ = 평 × 400 ÷ 121, ㎡ → 평 = ㎡ × 121 ÷ 400, 결과는 소수 둘째 자리 반올림(사사오입)
- 분양 평형 대략 환산: 전용률 75% 가정 (`widget.html`의 `EXCL_RATIO`)
  - 입력값이 전용면적이라면: 분양 평형 ≈ 전용 평수 ÷ 0.75 (정수 반올림)
  - 입력값이 분양 평형(공급면적)이라면: 전용 ≈ 공급 × 0.75 (정수 반올림)
  - 10㎡ 미만이거나 100평을 넘으면 아파트 환산 카드는 숨김
- 글의 “흔히 부르는 분양 평형(보통)” 범위(59㎡ 24~25평형, 84㎡ 33~35평형, 114㎡ 43~46평형)는 법정 값이 아니라 통상 범위다. 단지마다 다르다.

## 출처 (기준일 2026-11-13)
- 1평 = 400/121㎡: 한국과학기술정보 학술지 자료(koreascience) https://koreascience.kr/article/JAKO200841557525802.pdf
- 법정계량단위와 평 사용 단속(2007-07-01 시행, 「계량에 관한 법률」): 국가기술표준원 https://www.kats.go.kr/content.do?cmsid=78 , 보도 https://www.mt.co.kr/article/2007062206164702138
- 공급면적 = 주거전용면적 + 주거공용면적(「주택공급에 관한 규칙」 제21조, 「주택법 시행규칙」), 법제처 법령해석 19-0240: https://www.law.go.kr/LSW/expcInfoP.do?expcSeq=329069

## 매년 할 일
환산 상수는 바뀌지 않는다. 법정계량단위 관련 법령이 바뀌면 FAQ “계약서에는 평으로 써도 되나요?”만 확인한다.

## 플랫폼별 붙여 넣는 곳
- **티스토리:** 글쓰기 → 우측 상단 `기본모드` → `HTML` 선택 → 붙여 넣기
- **블로거(Blogger):** 글쓰기 → 좌측 상단 연필 아이콘 → `HTML 보기` → 붙여 넣기
- **워드프레스(설치형):** 블록 추가 → `사용자 정의 HTML` → 붙여 넣기
  - wordpress.com 무료 요금제는 스크립트를 지워서 계산기가 작동하지 않음
