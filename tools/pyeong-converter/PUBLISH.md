# 발행 프롬프트: 평수 계산기

아래 내용을 Chrome이 연결된 세션(데스크톱 앱, Cowork)에 그대로 붙여 넣으세요.
제목·태그·카테고리·예약 일시는 발행하는 세션이 SEO 스킬과 블로그 현황을 보고 알아서 정합니다.


```
github.com/spgummo0905-alt/blog-tools 의 tools/pyeong-converter/post.html 글을
우리가 가지고 있는 블로그들 모두에(스레드 제외) HTML 모드로 붙여 넣고 예약발행해 줘.

[본문] 고정
- https://raw.githubusercontent.com/spgummo0905-alt/blog-tools/main/tools/pyeong-converter/post.html 의 내용 전체
- 계산기 코드와 본문 내용은 고치지 마. 단, 본문의 {{LINK:폴더명}} 은 이미 발행(또는 예약)된 해당 계산기 글 주소로 바꾸고, 아직 없는 계산기 줄은 지워 줘.

[제목·태그] SEO 스킬로 최적화
- 사용할 수 있는 SEO 최적화 스킬(on-page SEO, 키워드 리서치 등)을 써서 블로그별로 검색 키워드에 맞게 알아서 정해 줘.
- 참고용 기본안 (그대로 써도 되고 바꿔도 돼)
  - 제목: 평수 계산기 - 평↔㎡ 바로 변환 (59·84㎡는 몇 평?)
  - 태그: 평수계산기, 평수계산, 평제곱미터, 84제곱미터몇평, 59제곱미터몇평, 전용면적공급면적
- 같은 글이라도 블로그마다 제목을 조금씩 다르게 써서 중복 콘텐츠로 보이지 않게 해 줘.
- 플랫폼이 지원하면 메타 설명(요약)과 주소(슬러그)도 SEO에 맞게 정해 줘.

[나머지] 자율 판단
- 카테고리, 대표 이미지, 공개 설정, 예약 일시 등은 블로그마다 기존 구성과 예약 현황을 보고 알아서 정해 줘.
- 기준
  - 계산기 글은 같은 블로그에서 서로 최소 하루 간격을 둬 줘.
  - 기존 예약 글과 시간이 겹치지 않게 해 줘.
  - 검색 유입이 좋은 시간대를 골라 줘.

[마무리]
- 미리보기에서 계산기가 실제로 작동하는지(입력하면 결과가 나오는지) 확인해 줘.
- 블로그마다 정한 제목, 태그, 카테고리, 예약 일시, 글 주소를 표로 알려 줘.
```
