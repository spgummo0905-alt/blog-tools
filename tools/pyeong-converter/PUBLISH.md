카테고리는 필요하면 바꿔서 쓰면 됩니다. 예약 일시는 발행하는 세션이 알아서 정합니다.

> PR이 `main`에 머지된 뒤에 사용하세요. 머지 전에는 raw 주소에 파일이 없습니다.

```

우리가 가지고 있는 블로그들 모두에(스레드 제외) HTML 모드로 붙여 넣고 예약발행해 줘.

- 본문: https://raw.githubusercontent.com/spgummo0905-alt/blog-tools/main/tools/pyeong-converter/post.html 의 내용 전체
- 제목: 평수 계산기 - 평↔㎡ 바로 변환 (59·84㎡는 몇 평?)
- 태그: 평수계산기, 평수계산, 평제곱미터, 84제곱미터몇평, 59제곱미터몇평, 전용면적공급면적

  계산기 글끼리는 같은 블로그에서 최소 하루 간격을 두고, 같은 글은 블로그마다 같은 날에 올려 줘.

블로그마다 예약이 잡힌 글 주소를 알려 줘.
```
