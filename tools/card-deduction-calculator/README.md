# 신용카드 소득공제 계산기 (2026년 사용분, 2027년 초 연말정산)

| 파일 | 용도 |

| `widget.html` | 계산기만. 연말정산 글 등에 계산기만 넣고 싶을 때 사용 |

- **제목 추천:** 신용카드 소득공제 계산기 2026 - 25% 넘었을까? 체크카드·전통시장까지 공제액 바로 계산
- **태그:** 신용카드소득공제, 신용카드소득공제계산기, 체크카드소득공제, 연말정산카드공제, 신용카드공제한도, 2026연말정산

## 위젯이 하는 일
- 입력: 총급여(원, 칩 3천만~1억), 수단별 사용액 5칸(신용카드 / 체크카드·현금영수증 / 전통시장 / 대중교통 / 도서·공연·박물관·영화·수영장·헬스장), 기본공제 자녀 수(없음·1명·2명 이상), 한계세율 칩 8개(6.6~49.5%, 기본 16.5%).
- 총급여 7천만 원 초과면 문화 칸을 숨기고 "결제 수단 칸에 더해 넣으라"고 안내한다.
- 출력: 소득공제액, 예상 절세액(공제액 × 한계세율, 원 미만 버림), 사용액 vs 25% 문턱 막대, 상황별 안내, **다음 1만 원 표**(수단별로 1만 원을 더했을 때 공제액을 엔진으로 다시 계산한 차이와 세금 감소), 계산 과정 표와 식.
- 잘못된 입력: 총급여 0원·10억 원 초과, 사용액 칸 10억 원 초과, 사용액 전부 0 → 빨간 안내 후 결과 숨김.

## 계산 기준 (기준일 2026-11-26, 조세특례제한법 제126조의2, 2026. 1. 1.~12. 31. 사용분)
1. **최저사용금액** = 총급여 × 25%(원 미만 버림). 사용액 합계가 이 금액 이하면 공제 0.
2. **공제율**: 신용카드 15%, 직불·선불카드·현금영수증 30%, 도서·신문·공연·박물관·미술관·영화상영관·수영장·체력단련장(총급여 7천만 원 이하만, 체육시설은 2025. 7. 1. 이후 사용분) 30%, 전통시장 40%, 대중교통 40%. 각 수단 금액 × 공제율은 원 미만 버림.
3. **공제 제외 금액**(제2항): 최저사용금액을 신용카드 → 체크카드·현금영수증·문화 → 전통시장·대중교통 순으로 채운다고 보고
   - 최저 ≤ 신용카드: 최저 × 15%
   - 최저 ≤ 신용 + 체크 + 문화: 신용 × 15% + (최저 − 신용) × 30%
   - 그 외: 신용 × 15% + (체크 + 문화) × 30% + (최저 − 신용 − 체크 − 문화) × 40%
4. **공제 대상 금액** = 공제율 적용 합계 − 공제 제외 금액.
5. **기본 한도**: 총급여 7천만 원 이하 300만 원, 초과 250만 원. **자녀 추가 한도(2026년 신설, 2028년 사용분까지)**: 7천만 원 이하 1명당 50만 원(최대 100만 원), 초과 1명당 25만 원(최대 50만 원). `tools/year-end-tax-2027` README 와 같은 값.
6. **추가 공제** = min(공제 대상 − 기본 공제, 추가 한도, 전통시장·대중교통·문화 공제율 적용액 합계). 추가 한도: 7천만 원 이하 300만 원(전통시장·대중교통·문화 합산), 초과 200만 원(전통시장·대중교통 합산).
7. **절세액(추정)** = 소득공제액 × 한계세율(소득세율 6·15·24·35·38·40·42·45% × 1.1). 구간 이동·결정세액 0원은 반영하지 않는다(위젯과 글에 표시).
- **넣지 않은 것**
  - **소비증가분 추가 공제**(전년 대비 105% 초과분): 2024년 사용분(10%, 100만 원 한도) 등 한시 제도였고, 2026년 사용분에 적용된다는 공식 근거를 찾지 못했다(검색 결과 중 "2025. 12. 2. 국회 통과 개정안에서 제외"라는 해설도 있으나 원문 미확인). 그래서 브리프의 "전년 사용액(선택)" 입력은 만들지 않았다. 국세청 2026년 귀속 안내에 나오면 추가할 것.
  - **자녀 요건의 나이 기준**: "기본공제대상 자녀" 외 나이 요건(예: 18세 이하 등)은 공식 원문으로 확인하지 못해 위젯은 "기본공제 받는 자녀 수"로만 묻고, 맞벌이는 자녀를 기본공제로 올린 사람만 받는다고 안내한다. 국세청 안내로 재확인 필요.
  - 근로소득금액 한도, 중고차 10% 등 세부 포함·제외 항목(글에서 안내만), 2026년 한시 공제율 상향(확인된 것 없음).

### 2027년 사용분 (정부안, 국회 처리 전)
- 2026년 세제개편안(재정경제부, 2026. 8. 3.): 2027. 1. 1. 이후 과세기간부터 대중교통 40% 우대 공제율 폐지(일반 공제율 적용), 도서·공연 등 문화비 소득요건 폐지, 추가 공제 한도 축소(보도상 300→200만 원, 200→100만 원; 원문 미확인이라 글에는 넣지 않음).
- 2026-11-26 현재 국회 처리 전이라 연도 칩 없이 2026년 사용분만 계산하고, 위젯 주석·FAQ에 "국회 처리 전"으로 표시했다. 12월 국회 통과 법률을 확인한 뒤 2027년 사용분 글/칩을 만든다.
