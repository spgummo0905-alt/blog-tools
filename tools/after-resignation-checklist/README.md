# 퇴사 후 할 일 타임라인 (실업급여·건강보험·국민연금 기한)

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 타임라인 + 계산법·표·설명 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 타임라인만. 다른 글에 넣고 싶을 때 사용 |

- **제목 추천:** 퇴사 후 해야 할 일 총정리 - 실업급여·건강보험·국민연금 기한 타임라인
- **태그:** 퇴사후해야할일, 퇴사체크리스트, 실업급여신청기간, 퇴사후건강보험, 국민연금납부예외, 퇴직금지급기한

## 위젯이 하는 일
- 입력: 퇴사일(마지막 근무일, 기본 오늘, 2025-01-01~2027-12-31), 퇴사 사유(비자발/자발), 재취업 회사(없음/정해짐), 피부양자 가능 여부(모름/가능/어려움).
- 할 일 카드를 날짜순으로 보여 준다. 카드마다 날짜·요일, 오늘 기준 D-day(지났으면 "n일 지남"으로 흐리게 + "지났어요" 안내), 중요도(꼭 챙기기/중요/참고), 종류(법정 기한/권장/회사가 할 일/고지서 기준), 어디서·필요 서류·놓치면 한 줄씩. 체크박스는 저장하지 않는다.
- 맨 위에는 아직 안 지난 가장 가까운 법정 기한(권장·회사 몫 제외)의 D-day.
- 결과 복사는 ☐/☑ 체크리스트 텍스트.
- 조건별 표시
  - 재취업 정해짐: 이직확인서·실업급여·국민연금·피부양자·임의계속가입·수급기간 카드 숨김, 연말정산 카드 문구를 "새 회사 합산 또는 5월 신고"로.
  - 자발적 퇴사: 실업급여 카드를 "대상인지 확인(정당한 사유)" 참고 카드로, 수급기간 카드 숨김.
  - 피부양자 가능: 임의계속가입 카드 숨김 / 어려움: 피부양자 카드 숨김 / 모름: 둘 다.

## 기한 계산 규칙 (기준일 2026-11-20)
L = 마지막 근무일, Q = L + 1일(퇴직일 = 4대보험 자격 상실일 = 고용보험법의 "이직일 다음 날").

| 항목 | 위젯 계산 | 근거 | 확인 상태 |
|---|---|---|---|
| IRP 계좌 개설·통보 | L (권장 시점) | 근로자퇴직급여 보장법 제9조 제2항: 퇴직급여는 근로자 지정 IRP로 이전이 원칙, 55세 이후 퇴직 등 예외. 소득세법 제146조 제2항: 퇴직소득을 지급받은 날부터 60일 이내 연금계좌 입금 시 원천징수 안 함(이미 징수분 환급) | 검색 결과·해설로 확인 |
| 이직확인서 요청 | Q (권장) | 사업주는 요청받은 날부터 10일 이내 발급(고용보험법 시행규칙 제82조의2로 인용됨) | 해설 사이트로만 확인. 조문 번호 원문 미확인 → 글에는 "고용보험법 시행규칙"으로만 적음 |
| 구직신청·실업급여 신청 | Q (권장, 법정 마감 없음) | 고용보험법 제48조 제1항: 이직일 다음 날부터 12개월 내 소정급여일수 한도로 지급. 제2항 수급기간 연기(임신·출산·육아·질병 등) | 다수 자료 일치 |
| 퇴직금 | L + 14일, 토·공휴일이면 다음 평일 | 근로자퇴직급여 보장법 제9조 제1항(지급사유 발생일부터 14일, 합의로 연장 가능). 법제처 법령해석: 기간말일의 종료로 만료, 기간 계산은 민법 제155~161조 | 법제처 해석 검색 요약으로 확인 |
| 마지막 월급·미사용 연차수당 | L + 14일, 같은 규칙 | 근로기준법 제36조(금품 청산 14일), 제37조·시행령 제17조(지연이자 연 20%) | 일반 법령 지식 + 검색 결과. 원문 접속 불가 |
| 4대보험 상실신고(회사) | Q가 속한 달의 다음 달 15일(휴일이면 다음 평일) | 국민건강보험법 제10조 제2항(자격 잃은 날부터 14일 이내), 국민연금·고용보험 다음 달 15일 | 건강보험 14일은 조문 인용으로 확인, 고용보험 다음 달 15일은 해설 자료로 확인(시행령 제7조 원문 미확인). 회사 의무라 "확인만" 카드 |
| 국민연금 지역가입 신고·납부예외 | Q가 속한 달의 다음 달 15일, 휴일이면 다음 평일 | 국민연금법 시행규칙(지역가입자 자격 취득 신고: 사유 발생일이 속하는 달의 다음 달 15일), 국민연금공단 안내 | 공단 페이지·해설 일치. 늦게 신청했을 때 소급 여부는 자료가 엇갈려 글에 넣지 않음 |
| 피부양자 등록 | L + 90일(= Q를 1일째로 90일째), 휴일이면 다음 평일 | 국민건강보험법 시행규칙 제2조 제2항: 자격 변동일부터 90일 이내 신고하면 변동일로 소급, 넘기면 신고일부터 | 조문 인용·행정심판 사례로 확인. Q가 0시 시작이라 초일 산입(민법 제157조 단서)으로 보수적으로 계산 |
| 임의계속가입 | 날짜 없음("고지서 받으면") | 국민건강보험법 제110조, 시행규칙: 최초 지역보험료 고지 납부기한부터 2개월 이내 신청, 퇴직 전 18개월 중 직장가입 통산 1년 이상, 최대 36개월 | 공단 소식지·정책브리핑 일치. 첫 고지서 시점은 사람마다 달라 날짜를 계산하지 않음. 보험료 50% 경감 여부는 확인 못 해 넣지 않음 |
| 실업급여 수급기간 끝 | (Q + 12개월) − 1일, 휴일 미적용 | 고용보험법 제48조 제1항 | 기간 안에서 지급하는 것이라 말일 연장 대상 아님으로 판단 |
| 종합소득세 신고 | L의 다음 해 5월 31일, 토·일·공휴일이면 다음 평일 | 소득세법 제70조, 국세기본법 제5조. 경정청구 5년(국세기본법 제45조의2) | 확인 |

- "n개월 뒤 같은 날"이 없으면 그 달 말일(민법 제160조 제3항).
- 공휴일: 2026·2027년은 관공서 공휴일·대체공휴일·임시공휴일 전체(2026: 6/3 지방선거 포함, 노동절·제헌절 포함 / 2027: `tools/holidays-2027` 데이터와 동일). 그 밖의 해(2025, 2028)는 토·일과 양력 고정 공휴일만 반영하고, 결과에 "음력 공휴일 미반영" 안내를 띄운다.

## 확인하지 못한 것 / 주의
- 법령 원문(law.go.kr)을 직접 열어 보지 못했다. 조문 번호는 검색 요약에 나온 대로 적었다.
- 퇴직금 14일의 기산(초일 산입 여부): 위젯은 마지막 근무일 + 14일로 계산(퇴직일을 1일째로 세는 것과 같은 날). 하루 차이 해석이 있을 수 있다.
- 2026년 퇴직급여법·고용보험법 개정 논의(퇴직연금 사외적립 의무화, 실업급여 주 6일 지급 등)는 14일 지급·12개월 수급기간을 바꾸지 않는 것으로 확인했다. 실업급여 산정 기준 변경은 2028년 시행 예정이라 글에 넣지 않았다.
- 실업크레딧(보험료 75% 지원)은 공단·언론 자료로 확인했지만 금액·한도는 글에 넣지 않았다.
