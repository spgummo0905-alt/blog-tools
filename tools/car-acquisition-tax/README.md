## 계산 기준 (기준일 2026-11-26, 비영업용)
- 취득세 = 과세표준 × 세율 − 감면액. 감면 전 세액은 10원 미만 버림, 2자녀 50% 감면액도 10원 미만 버림.
- 세율(지방세법 제12조 제1항 제2호): 비영업용 승용 7%, 경자동차 4%, 그 밖의 비영업용(승합·화물) 5%, 영업용 4%(계산기 대상 아님). 전기·수소·하이브리드 승용도 7%.
- 과세표준
  - 신차: 사실상 취득가격 = 부가세 제외 공급가액. 입력이 부가세 포함이면 `Math.round(가격 ÷ 1.1)`. 할인 후 실제 금액·옵션 포함. 전기차 보조금은 차감하지 않음.
  - 중고차(유상승계취득): 사실상 취득가격. 신고가액이 시가표준액보다 적으면 시가표준액(지방세법 제10조의5 제1항 제2호 단서로 알고 있으나 원문 미확인, 아래 참고). 계산기는 시가표준액을 입력하면 `max(거래가, 시가표준액)`, 비우면 거래가.
- 면세점(지방세법 제17조): 취득가액 50만원 이하 → 0원. 계산기는 과세표준 ≤ 500,000원이면 0원.
- 감면(지방세특례제한법). 중복 감면은 안 되고 큰 것 하나만(제180조) → 계산기는 후보 중 감면액 최댓값 하나만 적용.

| 감면 | 2026년 | 2027년 | 근거 |
|---|---|---|---|
| 경형 승용차 | min(세액, 75만원) | 같음 (기한 2027-12-31) | 제67조 |
| 전기차 | min(세액, 140만원) (기한 2026-12-31) | **정부 개정안** min(세액, 70만원), 기한 2029-12-31로 연장. 국회 심의 중(미확정). 미통과 시 감면 없음 → 위젯이 "개정안 통과 안 되면" 세액을 카드로 같이 표시 | 제66조 |
| 수소전기차 | min(세액, 140만원) | 같음 (기한 2027-12-31, 수원시 안내) | 제66조 |
| 다자녀 3자녀 이상 | 6인승 이하 승용: min(세액, 140만원) / 7~10인승 승용·15인승 이하 승합·1톤 이하 화물: 전액 | 같음 (기한 2027-12-31) | 제22조의2 |
| 다자녀 2자녀 | 6인승 이하 승용: min(세액×50%, 70만원) / 그 밖: 50% | 같음 | 제22조의2 |
| 하이브리드 | 없음 (2024-12-31 종료) | 없음 | |

- 위젯에서 경차는 6인승 이하로 보고, 승합·화물은 정원 선택 없이 다자녀 비율만 적용(15인승 이하·1톤 이하 조건은 안내 문구로).
- 공채(도시철도·지역개발채권), 번호판·증지대, 농어촌특별세, 장애인·국가유공자 감면은 계산하지 않고 안내만.

## 확신이 덜한 부분
- **2027년 전기차 감면**: 정부안(70만원, 2029년까지)이 2026-11-26 현재 국회 통과 전. 통과·수정·미통과 여부를 12월 본회의 후 반드시 확인.
- 수소전기차 기한 2027-12-31은 수원시 안내 기준. 전기·수소를 같이 2026년 말로 적은 민간 자료도 있음. 2026년 개편안이 수소차도 건드리는지 확인 못 함.
- 다자녀 2자녀 6인승 이하 70만원 한도의 조문 문구(“140만원 이하면 50%, 초과면 70만원 공제” 등)는 원문 미확인. 결과는 min(50%, 70만원)과 같다고 보고 계산.
- 중고차 "시가표준액보다 낮으면 시가표준액" 규칙의 현행 조문 번호(제10조의5)는 원문을 직접 보지 못함. 위택스·지자체·연구원 자료의 공통 설명을 따름.
- 감면분 농어촌특별세(감면세액의 20%) 부과 여부는 감면 종류별로 확인하지 못해 계산에서 뺌.
