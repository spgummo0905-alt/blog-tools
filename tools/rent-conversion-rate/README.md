## 계산 기준 (기준일 2026-11-26)
주택임대차보호법 제7조의2, 시행령 제9조(2020. 9. 29. 개정 시행, 가산 이율 3.5% → 2%).

- **법정 상한 전환율** = min(연 10%, 한국은행 기준금리 + 연 2%). 기준금리 3.25% → **5.25%**
- 위젯 위쪽 "기준금리" 칸은 기본값 3.25%이고 사용자가 고칠 수 있음(0~20%, 소수 둘째 자리). 상한은 bp(0.01%p) 정수로 계산
- **전세 → 월세**: 월세 상한(원) = floor((지금 보증금 − 바꿀 보증금)[만원] × 상한bp ÷ 12). 바꿀 보증금은 0 이상, 지금 보증금보다 적어야 함
- **월세 → 전세**: 환산 보증금 = 보증금 + 월세 × 12 ÷ 전환율, 만원 미만 버림. 전환율 칸을 비우면 법정 상한, 직접 넣으면 0.01~30%. 이 방향은 법정 상한이 없다고 안내
- **집주인 제안 검사**: 적용 전환율 = (제안 월세 − 지금 월세) × 12 ÷ (지금 보증금 − 제안 보증금). 초과 판정은 정수 비교 `ΔM×120000 > ΔA×상한bp`. 상한 월세 = 지금 월세 + floor(ΔA × 상한bp ÷ 12), 초과액 = 제안 월세 − 상한 월세
  - 제안 보증금 ≥ 지금 보증금이면 "전환율 상한 대상이 아니에요" 상태(월세만 인상 = 증액 5% 안내, 보증금↑월세↓ = 월세→보증금 전환이라 상한 없음)
  - 표시 전환율은 소수 둘째 자리 반올림, 초과인데 반올림 값이 상한과 같아 보이면 셋째 자리 버림으로 표시
- 입력: 금액은 모두 만원 단위 정수(최대 9,999,999만원)
- 2027년 1월 1일에 바뀌는 법정 값은 없어서 연도 칩은 두지 않음. 상한은 기준금리 결정일마다 바뀜

## 확인하지 못한 점 (솔직히 기록)
- 한국은행 누리집 원문을 직접 열지 못했어요. 3.25%는 검색 엔진에 잡힌 한은 기준금리 추이 페이지 캐시와 여러 언론 속보로 확인했어요. 발행 전 한은 누리집에서 한 번 더 보면 좋아요.
- 한국부동산원 지역별 전월세전환율 최신 수치는 공식 출처로 확인하지 못해 글에 숫자를 넣지 않았어요(개념과 R-ONE 조회 방법만 안내).
- "신규 계약에는 법정 상한이 적용되지 않는다"는 법 조문 자체가 아니라 국토부 해설(계약 존속 중·갱신 시 적용)과 일반적 해석을 따른 설명이에요.
- 제10조의2(초과 차임 반환청구) 조문은 원문을 직접 열지 못했고 기존 지식과 해설로 적었어요.
