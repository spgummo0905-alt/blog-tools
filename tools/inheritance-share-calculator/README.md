# 법정상속분 계산기

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 계산기 + 계산법 + 순위·구성별 표 + 대습상속·유류분·상속포기 설명 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 계산기만 |

- **제목 추천:** 법정상속분 계산기 - 배우자·자녀 몇 대 몇? 상속인별 비율과 유류분 바로 계산
- **태그:** 법정상속분, 법정상속분계산기, 상속순위, 배우자상속비율, 유류분, 대습상속
- 말투: 민감한 주제라 차분하고 정중하게. 과장·광고 문구 금지. "법률·세무 자문이 아니며 개별 사정에 따라 다름, 대한법률구조공단(132)·변호사·세무사·가정법원 상담" 안내를 위젯과 글에 모두 둠.
- 상속세는 계산하지 않음(글에서 별도 확인 안내).

## 위젯 동작
- 입력: 배우자 있음/없음, 살아 있는 자녀 수, 먼저 사망한 자녀 수(최대 9) → 자녀별로 "배우자(며느리·사위) 있음" 칩 + 손주 수, 자녀가 없으면 부모님(두 분/한 분/안 계심) → 안 계시면 조부모님 수(최대 4), 배우자·직계존속이 없으면 형제자매 수 → 0이면 가장 가까운 4촌 이내 친척 수. 상속재산·빚(선택, 원, 천 단위 콤마, 한글 금액 표시).
- 출력: 상속 순위 배지, 첫 상속인 몫(큰 분수), 상속인 그룹별 카드(분수, 비율, 받는 재산, 나눠 갚을 빚, 재산 − 빚, 유류분 분수·금액), 계산식, 빚 > 재산이면 상속포기·한정승인 경고. 상속인이 없으면 특별연고자 분여·국가 귀속 안내.
- 잘못된 입력: 자녀·형제자매 30명 초과, 조부모 4분 초과, 금액 1경 원 이상 → 빨간 안내.
- 분수는 정수 가중치(배우자 3, 그 밖 2 = 1.5:1의 2배)로 계산 후 최대공약수로 약분. 금액은 원 단위 반올림(합계가 1원 정도 다를 수 있음).

## 계산 기준 (기준일 2026-11-26)

| 항목 | 내용 | 근거 |
|---|---|---|
| 상속 순위 | 1순위 직계비속, 2순위 직계존속, 3순위 형제자매, 4순위 4촌 이내 방계혈족. 같은 순위는 최근친 우선, 같은 촌수는 공동상속 | 민법 제1000조 |
| 배우자 | 직계비속·직계존속과 같은 순위로 공동상속, 둘 다 없으면 단독 | 민법 제1003조 제1항 |
| 대습상속 | 상속인이 될 직계비속·형제자매가 먼저 사망하면 그 직계비속이, 배우자는 그 배우자도 대습상속 | 민법 제1001조, 제1003조 제2항, 제1010조 |
| 법정상속분 | 같은 순위는 균분, 배우자는 직계비속·직계존속 상속분의 5할 가산 | 민법 제1009조 |
| 유류분 | 직계비속·배우자 법정상속분의 1/2, 직계존속 1/3. 형제자매(구 제4호)는 2024. 4. 25. 헌법재판소 위헌 결정으로 효력 상실 | 민법 제1112조 |
| 2026년 유류분 개정 | 2026. 2. 12. 국회 통과, 2026. 3. 17. 공포·시행(법률 제21454호로 보도). 유류분 상실 사유 신설, 기여분 반영(제1008조 단서 관련), 가액반환 원칙(제1115조). 비율(1/2, 1/3)은 유지 | 법률 전문지·로펌 해설 |
| 상속권 상실(구하라법) | 미성년 자녀 부양의무 중대 위반 등 → 가정법원 선고로 상속권 상실. 2024. 8. 28. 국회 통과, 2026. 1. 1. 시행 | 민법 제1004조의2 |
| 상속포기·한정승인 | 상속개시 있음을 안 날부터 3개월 | 민법 제1019조 |
| 자녀 전원 상속포기 | 배우자가 단독상속인 (종전 2013다48852 변경) | 대법원 2023. 3. 23.자 2020그42 전원합의체 결정 |
| 상속인 부존재 | 특별연고자 분여, 국가 귀속 | 민법 제1057조의2, 제1058조 |

**매년 갱신할 값:** 없음(법정 비율은 민법 개정 시에만 바뀜). 민법 상속편·유류분 조항이 다시 개정되면 위젯 비율과 글의 "2026년 개정 민법" 문단을 고친다.

## 넣지 않은 것 / 확인 한계
- 생전 증여(특별수익), 기여분, 유증, 상속세는 계산하지 않음. 유류분 금액은 "상속재산 − 빚"만으로 어림(산입 증여 미반영)이라고 위젯·글에 명시.
- 형제자매의 대습상속(먼저 사망한 형제자매의 자녀)과 재대습(손주도 먼저 사망)은 입력을 받지 않음.
- 자녀 전원이 상속을 포기한 경우는 위젯이 직접 계산하지 않고(부모 순위로 넘어가는 입력 흐름이 됨) 힌트와 FAQ로 2020그42를 안내.
- 2026년 개정 민법의 공포일·법률번호는 언론·로펌 해설 기준(원문 미열람). 2026. 3. 17. 전에 개시된 상속은 구법(원물반환 원칙)이 적용된다는 해설이 있으나 글에는 "2026. 3. 17. 이후 개시된 상속은 원칙적으로 가액반환"만 적음.
- 2024. 4. 25. 이전에 개시된 상속에서 형제자매 유류분(1/3)이 어떻게 처리되는지는 사건별로 달라 다루지 않음.

## 플랫폼별 붙여 넣는 곳
- **티스토리:** 글쓰기 → 우측 상단 `기본모드` → `HTML` 선택 → 붙여 넣기
- **블로거(Blogger):** 글쓰기 → 좌측 상단 연필 아이콘 → `HTML 보기` → 붙여 넣기
- **워드프레스(설치형):** 블록 추가 → `사용자 정의 HTML` → 붙여 넣기
  - wordpress.com 무료 요금제는 스크립트를 지워서 계산기가 작동하지 않음
