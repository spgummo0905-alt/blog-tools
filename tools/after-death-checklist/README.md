# 가족 사망 후 할 일 타임라인

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 타임라인 위젯 + 기한 계산법 + 표 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 타임라인 위젯만 |

- **제목 추천:** 가족 사망 후 해야 할 일 - 사망신고·상속포기·상속세 기한 순서대로 정리
- **태그:** 사망후해야할일, 사망신고기한, 상속포기기한, 안심상속원스톱서비스, 상속세신고기한, 자동차상속이전
- 말투: 민감한 주제라 차분하고 정중하게. 광고·과장 문구 금지. "법률·세무 자문이 아니며 상황에 따라 다름, 대한법률구조공단(132)·세무사 상담" 안내를 위젯과 글에 모두 둠.

## 위젯 동작
- 입력: 돌아가신 날(오늘 기본), 사망 사실을 안 날(선택, "나중에 알게 되셨나요?"), 재산·빚(재산이 더 많음/빚이 더 많거나 비슷/모름/거의 없음), 고인 명의 자동차·부동산(복수 선택), 연금(국민연금/공무원·사학·군인연금/모름/해당 없음).
- 출력: 할 일 카드(중요도 배지, 기한 날짜·요일, D-day 또는 "기한 지남", 근거 규칙, 어디서·필요 서류·놓치면). 지난 항목은 흐리게 + "지났어요. 지금이라도 …" 안내. 체크박스로 완료 표시(저장 안 함). 결과 복사는 `[ ]`/`[v]` 체크리스트.
- 순서: 사망신고 → 안심상속(기한은 1년이지만 사망신고 때 함께 권장) → 통신·공과금 → 건강보험 → 상속포기·한정승인 → 예금 정리 → 그 밖은 기한순.
- 표시 조건: 준확정신고·상속세는 재산이 "거의 없음"이면 숨김. 부동산·자동차는 선택 시만. 국민연금은 "국민연금" 또는 "모름"일 때, 공무원 등 연금은 해당 선택 시만.
- 기한 계산 (기준일 2026-11-20)
  - "~한 날부터 n개월": 초일 불산입, n개월 뒤 같은 날짜에 만료, 그 날짜가 없으면 그 달 말일(민법 제157·160조). 코드 `addMonths`.
  - "사망일이 속한 달의 말일부터 n개월": n개월 뒤 달의 말일. 코드 `monthEndPlus`.
  - 말일이 토·일요일·공휴일이면 다음 날(민법 제161조, 국세기본법 제5조). 공휴일 = 매년 고정 공휴일(2026년부터 노동절 5/1·제헌절 7/17 포함) + 2026·2027년 설·추석·대체·임시공휴일(`EXTRA`). **매년 갱신할 값: 다음 해 월력요항 발표 후 `EXTRA`에 추가.** 2028년 이후 설·추석·대체공휴일과 2025년 이전 음력 공휴일은 반영하지 않음(주말·고정 공휴일만).

## 넣지 않은 것 (확인 못 했거나 사실과 다름)
- **건강보험 장제비**: 현재 건강보험 급여에 없음(폐지 시점은 자료마다 달라 글에 쓰지 않음). 브리프 예시에 있었지만 제외.
- **자동차 이전등록 과태료 금액**, **상속세 가산세율**: 출처마다 금액·계산이 달라 "과태료가 부과돼요", "가산세가 붙어요"로만 표시.
- **휴대폰 해지가 안심상속 조회에 포함되는지**: 확인 못 해 쓰지 않음.
- **사학연금·군인연금 시효**: 공무원연금법 기준만 적고 "기관별로 확인" 표시.
- **노동절(5/1)을 국세기본법상 기한 연장일로 보는 것**: 2026년부터 공휴일이라 공휴일 목록에 포함(holidays-2027 README 근거).

## 확인 한계 (솔직히)
- 이 환경에서 law.go.kr, korea.kr, nps.or.kr 은 직접 열리지 않아(DNS 차단) 검색 결과의 공식 페이지·지자체 안내 요약과 법률 해설로 교차 확인했어요. 기준일 2026-11-20.
- "사망 사실을 안 날"과 "상속개시 있음을 안 날"은 엄밀히 다를 수 있어요(상속인이 된 사실까지 안 날, 대법원 2012다59367). 위젯은 같은 날로 계산하고 글·FAQ에서 안내만 함.
- 상속세 신고기한 9개월(외국 주소)은 문구로만 안내하고 날짜 계산은 6개월로 함.
- 2026년 공휴일(설 2/16~18, 대체 3/2·5/25·8/17·10/5, 지방선거 6/3, 추석 9/24~26)은 언론 보도 기준.
