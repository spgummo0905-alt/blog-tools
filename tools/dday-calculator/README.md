# 디데이 계산기

| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 계산기 + 설명 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 계산기만. 다른 글에 계산기만 넣고 싶을 때 사용 |

- **제목 추천:** 디데이 계산기 - D-day, 날짜 사이 일수, 100일·1000일 기념일 한 번에
- **태그:** 디데이계산기, 디데이, 날짜계산기, 날짜수계산, 100일계산, 기념일계산기

## 계산 기준
- 모든 날짜 차이는 `Date.UTC(년, 월-1, 일)` 로 만든 "일 번호"끼리 빼서 계산합니다. 시간대·서머타임 때문에 하루 밀리는 일이 없습니다. 오늘 날짜는 보는 사람 기기의 현지 날짜를 씁니다.
- **D-day:** 목표일 − 오늘 = N → `D-N` / 0이면 `D-Day` / 음수면 `D+N`. 오늘은 세지 않습니다(내일 = D-1).
- **날짜 사이:** 종료일 − 시작일. "시작일도 포함" 을 켜면 +1일. 시작일이 더 늦으면 두 날짜를 바꿔 계산하고 안내합니다.
  - 개월 표기는 달력 기준: 시작일에서 k개월 뒤 같은 날(그 달에 없으면 말일, 예: 1월 31일 + 1개월 = 2월 28일)이 종료일을 넘지 않는 최대 k + 남은 일수. 시작일 포함일 때는 종료일 + 1일까지로 셉니다(1월 1일~12월 31일 포함 = 1년).
- **며칠 후/전:** 기준일 ± N일. "기준일을 1일째로 세기"를 켜면 ± (N − 1)일. N은 0~100,000.
- **기념일:** 시작일을 1일로 셈. N일 기념일 = 시작일 + (N − 1)일. 목록은 100~1,000일(100일 단위), 1,500·2,000·2,500·3,000일, 1~10주년.
  - N주년 = 시작일과 같은 월·일. **2월 29일 시작이면 평년엔 2월 28일**로 표시합니다(연인 기념일 관행 기준으로 정함. 만 나이 계산기는 민법 기간 계산에 따라 3월 1일을 씀 — 용도가 달라 다르게 둠).
- 날짜 입력 범위: 1000~9999년. 없는 날짜(2월 30일, 13월 등)는 빨간 안내 문구.

## 출처 (기준일 2026-11-13)
- 민법 제157조(기간의 기산점): "기간을 일, 주, 월 또는 연으로 정한 때에는 기간의 초일은 산입하지 아니한다. 그러나 그 기간이 오전 영시로부터 시작하는 때에는 그러하지 아니하다." — 국가법령정보센터 https://www.law.go.kr/법령/민법/제157조 (이 작업 환경에서는 law.go.kr 접속이 막혀 있어 조문 해설 사이트 https://korea.legal/wiki/민법-제157조/ 로 확인함. 발행 전 원문 한 번 확인 권장)
- 100일·1주년을 세는 방식(시작일 = 1일)은 법령이 아닌 사회 관행이라 공식 출처가 없습니다.

## 플랫폼별 붙여 넣는 곳
- **티스토리:** 글쓰기 → 우측 상단 `기본모드` → `HTML` 선택 → 붙여 넣기
- **블로거(Blogger):** 글쓰기 → 좌측 상단 연필 아이콘 → `HTML 보기` → 붙여 넣기
- **워드프레스(설치형):** 블록 추가 → `사용자 정의 HTML` → 붙여 넣기
  - wordpress.com 무료 요금제는 스크립트를 지워서 계산기가 작동하지 않음
