- **제목 추천:** 퇴직금 계산기 - 입사일·퇴사일만 넣으면 퇴직금 바로 계산 (평균임금 계산법)
- **태그:** 퇴직금, 퇴직금계산기, 퇴직금계산법, 평균임금, 퇴직금지급기준, 퇴직금계산

## 계산 기준 (2026-11-13 확인)
- **퇴직일** = 마지막 근무일의 다음 날 (고용노동부 퇴직금 계산기 입력 기준). 위젯은 기본으로 퇴직일을 받고, `마지막 근무일로 입력`을 누르면 마지막 근무일을 받아 +1일 해서 계산한다.
- **재직일수** = 퇴직일 − 입사일 (입사일부터 마지막 근무일까지, 양 끝 포함한 일수와 같음)
- **지급 대상** = 퇴직일 ≥ 입사일의 1년 뒤 같은 날짜 (2월 29일 입사는 3월 1일). 미만이면 "퇴직금 지급 대상이 아니에요"와 남은 일수 표시
- **퇴직 전 3개월** = [퇴직일의 3개월 전 같은 날짜, 퇴직일 전날]. 3개월 전 달에 같은 날짜가 없으면(예: 5월 31일 → 2월 31일) 다음 달 1일부터. 총일수는 89~92일
- **1일 평균임금** = (3개월 임금총액 + 연간 상여금 × 3/12 + 연차수당 × 3/12) ÷ 3개월 총일수, 소수 둘째 자리 반올림
- **퇴직금** = 1일 평균임금 × 30 × (재직일수 ÷ 365), 원 미만 버림
- 간단 입력 모드: 3개월 임금총액 = 월급 × 3. 월별 입력 모드: 위 3개월을 [3개월 전 같은 날, 2개월 전 같은 날), [2개월 전, 1개월 전), [1개월 전, 퇴직일) 세 구간으로 나눠 라벨에 날짜를 보여 준다.
- 계산하지 않는 것: 통상임금 비교(평균임금 < 통상임금이면 통상임금 적용 — 안내 문구만), 평균임금 산정 제외기간(육아휴직·출산휴가·휴업 등), 퇴직소득세(세전 금액으로 안내), 주 15시간 미만 판정(안내 문구만), DC형 퇴직연금

## 확인하지 못한 것
- 작업 환경에서 moel.go.kr·law.go.kr에 직접 접속이 막혀 있어서, 위 내용은 검색 결과에 나온 공식 페이지 요약으로 확인했다. 고용노동부 계산기에 같은 예시를 넣어 숫자를 직접 맞춰 보지는 못했다.
- 3개월 전 달에 같은 날짜가 없을 때(5월 29~31일 퇴직 등) 고용노동부 계산기가 시작일을 어떻게 잡는지 확인하지 못했다. 위젯은 "다음 달 1일"로 잡는다. 이 경우만 3개월 일수가 1~2일 다를 수 있다.
- 평균임금 소수점 처리(둘째 자리 반올림)와 퇴직금 원 미만 버림은 일반적인 실무 방식이며 고용노동부 계산기와 1원 단위까지 같은지는 확인하지 못했다.
