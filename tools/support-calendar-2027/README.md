| 파일 | 용도 |
|---|---|
| `post.html` | 블로그 글 본문 전체(도입부 + 위젯 + 설명 + 표 + FAQ). 글쓰기 화면의 **HTML 모드**에 통째로 붙여 넣기 |
| `widget.html` | 위젯만 (탭 2개: 나에게 맞는 지원금 / 월별 신청 달력) |

- **제목 추천:** 2027 정부 지원금 신청 일정 총정리 - 근로장려금·청년 지원·바우처 한눈에
- **태그:** 2027정부지원금, 근로장려금신청기간, 자녀장려금, 청년월세지원, 에너지바우처, 정부지원금신청일정

## 기준 (기준일 2026-11-13)
- 위젯은 **수급 판정이 아니라** 나이대·가구 형태·가장 어린 자녀·소득 종류·무주택 월세·수급 자격으로 1차 대상만 거른다. 소득·재산 기준은 문구로만 보여 주고 홈택스·복지로 모의계산을 권한다.
- 선택 규칙
  - 근로장려금: 소득 ≠ 없음. 가구 형태별 소득 기준·최대액 표시. 근로소득만이면 반기 신청 안내 추가
  - 자녀장려금: 소득 있음 + 자녀(만 18세 미만) 있음 + 1인 가구 아님
  - 부모급여+아동수당: 가장 어린 자녀 만 2세 미만 / 아동수당: 만 2~8세
  - 청년월세 지원: 19~34세 + 무주택 월세 / 청년미래적금: 19~34세 + 소득 있음
  - 에너지바우처: 기초생활수급자 / 문화누리카드: 기초생활수급자 또는 차상위
  - 청년문화예술패스: 19~20세 / 기초연금: 65세 이상 / 국민내일배움카드: 항상 표시
- 잘못된 입력(빨간 안내): 1인 가구 + 자녀 있음, 맞벌이 + 소득 없음, 나이·가구 형태 중 하나만 선택
- 2027년 일정이 **법령으로 정해진 것만 "확정"**. 근로·자녀장려금 정기 5월 1~31일, 반기 3월 1~15일·9월 1~15일, 기한 후 6월 1일~11월 30일(조세특례제한법의 장려금 신청 기간 규정, 매년 같은 기간). 마감일이 공휴일이면 다음 날로 늦춰짐(2027년 9월 15일은 추석 연휴와 겹칠 수 있으니 국세청 공지 확인).

### 확신이 낮은 부분
- 근로장려금 개편안의 국회 통과 여부(2026-11-13 현재 심의 중으로 확인). 통과 시 FAQ 2번, "2027년에 달라질 수 있는 것" 문구를 확정 표현으로 고친다.
- 국민내일배움카드 추가 한도(최대 500만원 등)는 출처마다 달라 "대상에 따라 추가"로만 적었다.
- 아동수당 지역별 추가액(비수도권 5천원, 인구감소지역 1만~2만원 등)은 출처마다 달라 숫자를 쓰지 않았다.
- 청년미래적금 소득 기준(일반형 총급여 6천만원·우대형 3,600만원 등)은 출시 전 보도와 차이가 있어 "기준 있음"으로만 적었다.
