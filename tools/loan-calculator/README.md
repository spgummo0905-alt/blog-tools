- **제목 추천:** 대출 이자 계산기 - 원리금균등·원금균등·만기일시 월 상환액 비교
- **태그:** 대출이자계산기, 대출계산기, 원리금균등상환, 원금균등상환, 만기일시상환, 주택담보대출이자

## 계산 기준 (기준일 2026-11-13)
- 월 이자율 r = 연 이자율 ÷ 12. 매달 이자 = 남은 원금 × r (원 단위 반올림).
- 원리금균등: 월 상환액 = P·r(1+r)^n / ((1+r)^n − 1), 원 단위 반올림. 이율 0%면 P ÷ n. 원금 = 월 상환액 − 그달 이자.
- 원금균등: 매달 원금 = P ÷ n (원 단위 반올림) + 그달 이자.
- 만기일시: 매달 이자만, 마지막 회차에 원금 전액 + 이자.
- 마지막 회차는 남은 원금을 모두 갚도록 맞춰 잔액 0원(끝전 정리로 마지막 회차 금액이 몇 원~몇백 원 다를 수 있음).
- 거치기간: 대출 기간에 포함. 거치기간 동안 이자만 내고 n − 거치 개월로 원금 상환. 만기일시 방식에는 적용하지 않음.
- 입력 범위: 대출금 1만원~(7자리 만원), 연 이자율 0~30%, 기간 1~600개월.
- 실제 은행은 일할 계산(실제 일수/365)·끝전 처리 방식이 달라 몇 원~몇백 원 차이 날 수 있다고 위젯과 글에 안내.
- 법정 수치를 쓰지 않는 순수 수학 계산이라 매년 바꿔야 할 상수는 없어요.
