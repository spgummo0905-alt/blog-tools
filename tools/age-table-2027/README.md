- **티스토리:** 글쓰기 → 우측 상단 `기본모드` → `HTML` 선택 → 붙여 넣기
- **블로거(Blogger):** 글쓰기 → 좌측 상단 연필 아이콘 → `HTML 보기` → 붙여 넣기

## 계산 기준 (2026-11-13 확인)
- **입력:** 출생연도(1930~2027, 4자리), 기준 연도 칩(2026 / **2027 기본** / 2028), 생일 칩(지난 뒤 기본 / 지나기 전). 출생연도 > 기준 연도면 빨간 안내.
- **나이:** 연 나이 = 기준 연도 − 출생연도. 만 나이 = 연 나이(생일 지난 뒤), 연 나이 − 1(생일 전). 기준 연도에 태어난 경우 생일 전은 "출생 전".
- **띠·60갑자:** 1984년 = 갑자년. 천간 = 甲乙丙丁戊己庚辛壬癸[(연도 − 4) mod 10], 지지·띠 = 子丑寅卯辰巳午未申酉戌亥(쥐…돼지)[(연도 − 4) mod 12]. 색 = 천간 오행(갑을 푸른, 병정 붉은, 무기 황금, 경신 흰, 임계 검은). **양력 1월 1일 기준**이며 음력 설·입춘 기준이면 1~2월생은 다를 수 있다고 위젯·글에 표시.
  - 검산: 1984 갑자, 1995 을해, 2000 경진, 2007 정해, 2016 병신, 2026 병오(붉은 말), **2027 정미(붉은 양)**, 1930 경오.
- **학년(기준 연도 3월~):** g = 기준 연도 − 출생연도 − 6. g ≤ 0 미취학(출생연도 + 7년 3월 입학), 1~6 초1~6, 7~9 중1~3, 10~12 고1~3, 13 대학 1학년 나이, 14 이상 "(출생연도 + 19)학번 나이"(재수·휴학 없이 가정). 2027년: 초1 = 2020년생, 고3 = 2009년생, 27학번 = 2008년생.
  - 빠른년생(2002년 1~2월생까지 한 해 위 학년으로 입학), 조기·유예 입학, 재수·휴학은 계산하지 않고 안내만.
- **나이 이정표** (기준 연도 이후에 오는 것만 표시, 지난 것만 있으면 "모두 지났어요"):

## 확인하지 못한 것
- 이 환경에서 law.go.kr·easylaw.go.kr 원문에 직접 접속하지 못해, 조문은 검색 결과·조문 사본(korea.legal, 위키문헌)·언론 해설로 교차 확인했다. 민법 제4조(19세 성년)는 잘 알려진 조문이라 별도 원문 확인 없이 썼다.
- 2027년에 예정된 전국 단위 선거 일정은 글에 넣지 않았다(선거권은 "선거일 현재 만 18세"라는 기준만 안내).
- 2028학년도 수능 날짜(2027년 11월)는 발표 전이라 글에 날짜를 넣지 않고 "그해 말 수능"으로만 썼다.
- 간지의 색(붉은 양 등)은 천간 오행에 따른 통속적 표현이다.
